# M9 自由选仓多批次小算例

这是人工几何与人工费用的机制验证例，包含一个总仓、两个已有前置仓、两个顾客、
两笔各需一箱的订单。坐标、时间与费用不代表真实经营参数。

顾客 C1 在 (3,0)，C2 在 (9,0)，前置仓 S1 在 (2,0)，S2 在 (8,0)，总仓 D 在 (0,0)。
输入参考分仓为 C1→S2、C2→S1，M8 固定该分仓，M9 允许重新选择。
订单 o1 在周期开始时释放，o2 在第40分钟释放；服务窗和最短使用时长见 orders.json。
周期90分钟，清洗3分钟，每阶段至少15分钟，所以完整 K 域为 {1,2,3}。

K=1 不能在第0分钟装载第40分钟才释放的 o2；K=3 无法让两笔不可拆订单覆盖三个非空批。
这些候选仍保留在完整 MILP 中，不用外层删除来缩小证明范围。
模型应选择实际两批，并在第一批回运清洗后复用一个实体箱。

运行入口为 [model9_demo.json](../../../config/experiments/examples/model9_demo.json)。
同配置加 `--model 8 --solver exact` 可得到固定分仓对照，二者使用相同 seed=42。
首次结果见 [小算例报告](../../../output/experiments/model9_small_exact_20261030/README.md)。
