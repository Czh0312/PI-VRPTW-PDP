# 一级容量50箱候选情景

从 mechanism_l05_3sat_balanced_v1 派生。一级车体积容量50、重量容量1000基准单位；其余物理数据、分仓及车队数量不变。重量上限为暂定机制参数，不宣称业务校准。

当前实现要求每个非空仓—批次恰好一次完整的一级配送。同一仓同一批不能由两车分担。因此M3中S3需要54箱，超过50，被必要条件检查判定为容量不可行；增加车辆总数也不能解除这个约束。

M8参考三批输入通过必要条件检查；原有35箱确定性可行见证在新容量下仍通过完整审计和两周期重放。本目录没有执行新的ALNS运行，不能把M3不可行与M8可行解释为经济性比较。

若采用同仓同批多车补给，需要同步修改数量分配、到货可用性、路线、容量、车辆占用以及独立审计。若保持现有模型结构，则需公开声明并重建分仓，使同仓同批需求不超过50，且两模型共享相同分仓。
