# 模型五与模型六共享数据

主入口为 `shared_v1_20261005/manifest.json`，包含395个配对场景、790个M5/M6配置，以及395个固定策略成本对照。使用同一组文件表达订单、网络、车队、清洗、周期边界和价格；模型差别通过决策配置表达。

M5固定日历、订单分批和箱池，以距离为目标；M6优化均匀批次数、共同分界、订单分批、箱池与路线，以成本为目标。M5所得方案按同一价格另行计价；固定策略成本对照保持M5日历、分批与箱池，单独改用成本目标。

生成、审计、配对运行与验证结果见 [共享数据说明](../../docs/model5_model6_shared_dataset_20261005.md)。旧数据与历史结果保留，不能与本版按同名场景合并统计。
