# Model 5 中转路径收益机制实例（seed 105）

## 结论

在一个确定性生成的 4 顾客、单前置仓、2 辆 E2 车辆实例上，Model 5 找到一次真实
空容器接力，使总路径从 Model 3 的 103.999497 降至 95.556056：

| 模型 | 状态 | 目标值 | 接力数 |
|---|---|---:|---:|
| Model 3（禁止接力） | OPTIMAL | 103.999497 | 0 |
| Model 5（允许接力） | OPTIMAL（完整 M5 全局最优） | 95.556056 | 1 |

全局最优路径节约为 8.443442，即 Model 3 最优值的 8.12%。Model 3 与规范 Model 5
均已证明最优，因此这里比较的不是两个 incumbent，而是两个模型的精确最优值。

## 路线对比

Model 3：

```text
E1: D0 -> S0d -> S0p -> D0
E2 vehicle 0: S0 -> C1d -> C2d -> C2p -> C1p -> S0
E2 vehicle 1: S0 -> C3d -> C0d -> C0p -> C3p -> S0
```

Model 5：

```text
E1: D0 -> S0d -> S0p -> D0
E2 receiver 0: S0 -> C3d -> C1d -> C1p -> receive(C2 at C0) -> S0
E2 carrier 1:  S0 -> C2d -> pickup(C2) -> C0d -> C0p
                       -> drop(C2 at C0) -> C3p -> S0
```

接力链为：

```text
C2 --carrier vehicle 1--> C0 --receiver vehicle 0--> S0
```

- 原顾客取箱：C2，时刻 60.0；
- 交接点：C0；
- 携带车卸箱完成：90.5，容器可接收时刻 91.0；
- 接收车实际接收：156.445924；
- 容器重量/体积：2.0 / 1.0；
- 两辆车不同，且属于同一前置仓。

## 证明口径

精确求解器先枚举 16 个“每个容器直接回仓/中转一次”的顶层模式；宽分支难以闭合时，
再完备细分具体交接点并删除未选交接链。最终证书为：

| 字段 | 数值 |
|---|---:|
| `total_patterns` | 16 |
| `closed_patterns` | 16 |
| 固定 MIP 求解数 | 259 |
| 具体交接细分 MIP 数 | 244 |
| Model 5 最优上界 | 95.55605584047346 |
| Model 5 最优下界 | 95.55605584047346 |
| MIP gap | 0 |

其中 242 个细分模式直接以 `CUTOFF` 关闭，1 个硬模式在 30 秒重试后以 `CUTOFF`
关闭。整个分解不限制中转容器总数；每个容器只能选择直接回仓或一条 `TP→TD→RP`
链，因此仍严格满足“每个空容器最多中转一次”。完整运行约 905.7 秒。
