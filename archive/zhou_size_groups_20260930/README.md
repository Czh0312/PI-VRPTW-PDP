# 顾客数重新分组前的备份

2026-09-30，按用户最新定义调整为：小规模 7/10/12，中规模 20/30，大规模 50/100 顾客。
沿用每种顾客数 5 个 Zhou 算例，形成 35 个单批算例及 B2/B3 各 35 个配对配置。

- `before_changes.tar.gz`：变更前活动数据、生成器、相关测试与文档，共 519 个文件，备份后逐文件校验。
- `before_changes.json`：备份文件哈希、用户指定的规模映射和每档数量；`additional_before/` 另存后续调整的多批测试原件。
- `previous_dataset/`：原活动数据目录、清单及说明，保留原字节用于追溯。
- `preservation_verification.json`：新增场景、迁移路径、保留输入与暂停实验快照的核对记录。

原有 38 个基础场景全部保留，新增 20 个 Zhou 场景：10/12/20/30 顾客各 5 例。
原来的 5 个 50 顾客 Zhou 场景从中型移到大型，7 个 30 AOI LaDe 场景从大型移到中型。
全部 114 个旧案例配置均已核对，除路径、规模描述和来源说明外保持相同；346 个不同运行输入文件逐字节一致。
包括 50 顾客例的原车队、订单、送取窗口和池量，均不会因为规模标签变化而改变。
所有原始来源与已有实验结果保留，原暂停实验的 458 个冻结输入与 133 个源码快照校验通过，保持 PAUSED。

`previous_dataset/` 中的路径仍是归档前路径，不能直接作为当前可运行清单。
旧实验复现应使用其冻结输入与源码；完整恢复旧目录时应在隔离副本中按备份相对路径还原。
当前入口是 `data/manifest.json`，主对比清单是 `data/zhou_comparison.md`。
