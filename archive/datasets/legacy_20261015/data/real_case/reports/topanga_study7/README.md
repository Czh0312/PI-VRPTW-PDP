## 使用边界与接入建议

1. 现有杭州分布为 1/2/3/4 天对应 0.15/0.45/0.30/0.10，平均 2.35 天，并非均匀分布。经验数据主要补充早归还和长尾结构。
2. CLOSED_AT 是归还登记时间，论文说明分批登记。不能视为精确的客户空箱最早可回收时间，更不能直接构造小时级取件窗。迁移到杭州必须标为外部校准假设。
3. 缺少完整抽取口径和核销状态，456 条未归还不能解释为损失，也不能用 1-456/36890 估计最终回收率。无清洗完成、报废、车辆路径和真实运输矩阵字段。
4. 五个区域之间的归还流是用户交还地点变化，不是车辆间交接事件，也不是当前 M6/M7 跨仓调拨证据。
5. `*_elapsed_day_pmf.csv` 是对经过时长向上取整的诊断分布：0<L<=1 对应第 1 桶。论文样本向上取整后均值变成 2.961 天，不能误当成原始 2.393 天，也不能未经处理就替代现有日历日滞后。应明确采用小时级采样还是借出/归还日历日期差。
6. 新案例需处理同日归还、历史预热与长尾库存；七天研究窗不能把窗外归还丢弃或强制挤回 4 天内。可比较完整尾部与明确标注的截尾敏感性。
7. 先保持杭州空间网络、成本和求解协议一致，对比原时滞与经验时滞；再独立更新容器池测算和归还率敏感性。无需重跑 Zhou 算法基准。
