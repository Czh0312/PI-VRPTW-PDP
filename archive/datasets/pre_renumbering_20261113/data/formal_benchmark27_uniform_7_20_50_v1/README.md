# 统一规模27例：小7、中20、大50

每档9例，共27个基础算例，模型1～8共216个运行入口。实验先选每档前三例；完整数据保留全部27例。

对30/100顾客来源按卫星站与需求时段作确定性比例裁剪，分别保留20/50位顾客；7/20/50顾客来源保留原集合。保留所选顾客的全部需求、坐标、服务时间和时间窗，保留各来源的卫星站和车辆；箱池与池量上界同步为实际顾客数。同一基础算例的所有模型共用物理资源；同规模不同基础算例的车辆数不保证相同，详见design_summary.csv。

模型3显式使用总成本目标，与模型8共用经济参数。数据集保留原生可证K域；当前ALNS实验方案另行约束模型8 K=1～4、边界与截点按整分钟。
