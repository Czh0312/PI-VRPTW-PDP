# archive

本目录只保存不再属于当前实验主线、但仍可能用于追溯的历史材料。归档内容不应
直接进入论文主表，也不应作为当前模型编号或当前数据路径的示例。

- `legacy_results_pre_renumbering/`：旧数据或旧编号下的诊断与实验结果。
- `zhou_results_pre_renumbering/`：基于 Zhou 数据、但仍采用旧模型编号和旧路径字段的结果。
- `docs/`：旧设计、开发笔记、模型编号迁移、Model 7 与历史实验说明。
- `models/`：不再作为当前完整模型入口的列生成、分支定价、分解和早期实现。
- `experiments/`：旧数据、Model 7、研究探针和历史结果处理脚本。
- `reference/`：旧精确证据的归档说明；大体积中间产物不进入当前仓库树，可从 Git 历史追溯。
- `tests/`：不再属于当前功能回归范围的旧测试。
