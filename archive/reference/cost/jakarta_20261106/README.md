# 雅加达两级配送与包装成本核验

核验日期为 2026-11-06。雅加达是早期候选案例，实际案例数据集待定。候选方案拟采用当地价格，每条保留的配送记录对应一次包裹配送、使用一个箱子。原收寄任务移除，空箱回收时间窗另行设定。

本说明采用 academic-research-suite 的来源核验方法。仅形成证据与核算建议，未修改冻结算例、成本配置或求解器，未执行成本优化。机器登记见 [evidence.json](evidence.json)。

## 结论与适用边界

当地公开售价可以支持一组**相同标称尺寸**的纸箱与可重复使用 PP 箱价格参照。运输方面查到雅加达配送研究的公里成本、当地小型货车租金与平台计费说明，但尚不能建立覆盖全部费用、车型匹配且价格基期一致的运营成本配置。

现有 27 个正式经济配置全部为 `synthetic_mechanism` / `synthetic_units`：E1 距离系数 0.1、E2 距离系数 0.05、箱池周期系数 5、距离尺度 1。它们不是 IDR 成本，不能更换货币标签后作为雅加达实证价格。核对样本：`data/formal_benchmark27_uniform_7_20_50_v1/shared/large/L03/economic.json`。

原 [Zamal 等（2025）案例](https://pure.tue.nl/ws/portalfiles/portal/355235473/1-s2.0-S0305054825000449-main.pdf) 的两级车型为 minivan 与 motorbike，容量参数为 750、160，需求按货物重量解释。其目标中的行驶时间不是货币成本。项目旧中国中重卡/轻卡费用与中国包装价格不直接用于本地区配置。

两篇研究不能当成独立市场调查样本，也不能把两组数值的最小值和最大值包装成当前市场置信区间。它们适合保留为两组独立历史参照：`3319×D1 + 1970×D2` 与 `4687×D1 + 3397×D2`，D 为该层所有车辆的总行驶公里。这些公式仅重述文献系数的计价方式，不构成已推荐的正式经济配置。

进一步核验发现两处需谨慎：JAES PDF 的表 1 标题与运输成本表内容不符；IOP 全文副本的指数、图中里程与总成本不能用简单相乘复现（例如 1,433×3,397=4,867,901，图示总成本为 2,651,650）。目前尚未获得足够分项资料解释差异，因此不把其中任一组冻结为当前真实运营费率。PDF 截图未成功，不宣称完成视觉核对。

近期租金可作另一条标定路径的固定费用输入线索。例如 [Obet](https://obetrentcar.com/sewa-blind-van-jakarta-pusat/) 的 2026-10-07 页面列出 350,000 IDR/天，[Era Trans](https://sewamobiljakarta.co.id/sewa-rental-blind-van-di-jakarta/) 列出 400,000 IDR/天、5,500,000 IDR/月。不同服务和租期不可混成统一公里成本；长期租车月费也不能不说明运营天数就除以 30。

推荐正式核算采用可拆分结构：

`C_route = Σ[e=1,2] (c_e × D_e + w_e × T_e + F_e × V_e)`。

- `c_e`：只含明确未重复的能源、按里程维护等，IDR/km。
- `T_e`：付薪或车辆占用时间，须包括相应服务、等待和装卸；覆盖夜间时要明确班次。现有代码采用占用路线分钟，不含趟间闲置工资。
- `F_e × V_e`：明确按车辆和评价期发生的租金/固定费用；同一辆车多趟不重复按车日计费，超出租期另计。
- 采用已含人工、折旧等的综合公里价时，应删除其覆盖的对应分项，不能再全额加租金、人工。
- 平台客户运费与车队内部成本分别建模。[Lalamove 当前官方价目页](https://www.lalamove.com/en-id/pricing?city=jakarta) 要求通过应用取得实际价格，且有额外停靠、返程、装卸等费用。不能用其 2021 年旧每公里运价当作当前内部运营成本。

距离必须统一为 km：若适配器输出原始米距离，使用 0.001 换算；若输出已经是 km，不再缩放。由坐标生成的几何距离仍是路网距离的近似，不等同于实测道路里程。两层均累计配送、空箱回收、调拨和返站行驶；同一条已计费路线不再另按每箱加一笔重复回运费。

## 箱数、评价期与避免重复核算

设 Q 为配送箱次，B 为所需物理箱池，P_s=5,561、P_r=11,737 IDR/只。

一次性方案的箱体消耗为 `P_s×Q`。例如 CS-1 的 1,331 次配送，对应 7,401,691 IDR 的纸箱购置支出；不含运输和其他包装费用。这只是价格换算，没有求解路线。

循环方案建议同时报告两项：

1. 初始购箱资金 `P_r×B`，B 由配送回收及清洗可用时刻共同决定，不能直接等于 Q 或 `ceil(Q/批次数)`。
2. 同一评价期的费用 `C_route + h×B + (P_r/L)×Q + c_clean×R + c_track×Q + C_other`。h 只表示不与已计磨损重复的持有费用；R 是实际清洗箱次。寿命、清洗、损耗等没有匹配实测值时保留为假设或缺项。

上述两项分开报告，初始购置现金不再全额加入同一期磨损费用。若改用多日现金流，则改算初购、实际运营支出、补购减期末残值，不再重复计 P_r/L。丢失导致的补购也不能与已包含丢失退役的有效寿命重复核算。

每件包裹用一个箱子决定 Q，不决定循环池 B。同 Q 下，按使用次数摊销的 Q×P_r/L 通常不随分批数变化；缩小箱池首先节省初始资金及有依据的持有费。不能为使多批次经济而把每只箱的全部采购价当成每天的池费用。

## 本次可执行的研究结论

可以采用“雅加达真实配送任务 + 当地公开包装售价 + 显式运输成本情景”开展经济性分析。当前应报告价格基期混合与车型代理限制，不能称为 2026 年同一企业全部实测成本。

正式 IDR 配置仍需补齐：匹配 minivan/motorbike 的费用分解与运营强度、箱型承载/重量/回收折叠体积、同批量到仓价格、有效寿命、洗箱费用和箱池持有口径。缺项不是 0。成本敏感性改变相对系数时需要重新优化路线与分批，不能只给旧最优路线乘新价格。

现有 `models/cost/joint_batch.py` 的 `calibrated` 验证分支只接受 CNY；真正接入 IDR 时需扩展货币和证据单位校验，不能将 IDR 冒标 CNY。此项属于后续实施，本次未变更代码。
