# 模型9：自由选仓与不等长多批次容器循环联合优化

2026-10-30。M9 在当前 M8 的数学允许域上加入 M4 的顾客选仓决策，
联合优化分仓、订单分批、批次数、批次边界、逐批截点、箱池、两级路线与作业时刻。
当前实现为直接 Gurobi MILP，先完成精确求解。

## 业务边界

系统静态全信息，包含一个总仓、若干已有前置仓和顾客。选仓表示从已有前置仓中选择服务仓，
不增加选址、建仓、跨仓调拨或异仓回收。每个顾客在整个周期内只选一个前置仓；
该顾客全部订单的配送与空箱回收均经过同一选定仓。这与 M4 的顾客级分仓定义一致。
不同订单可以分入不同配送批次，同一订单及其箱量不可拆分。

M9 沿用 M8 的以下规则：

- 批次连续覆盖整个给定周期，长度与批内截点可分别优化，两阶段均满足最短时长。
- 每个计入 K 的批次都必须有正配送量和正回总仓量；两者不必相等，
  本批回收可来自前批配送，禁止用空日历段制造额外灵活性。
- 订单在所属批次开始装货前已释放。二级车辆可以在该批截点之后继续配送或取箱，
  截点只决定本轮一级回运资格。
- 二级在选定仓卸箱完成时刻恰等于截点的箱子归本轮；超过截点的进入后轮。
  本轮符合资格的箱量须全部取走，一级车在批末前卸回总仓。
- 只有实际卸回总仓且完成清洗的箱子才能再次领用；期末全部箱子回总仓且清洗完成，
  不增加隐藏末轮。车辆周转和连续两个周期的占用也须可行。

## 集合、输入与决策

| 记号 | 含义 |
| --- | --- |
| \(S,C,I\) | 前置仓、顾客、订单集合；订单 i 的顾客为 \(c(i)\) |
| \(S_c\) | 顾客 c 的允许仓集合；默认是所有前置仓 |
| \(q_i,g_i,r_i\) | 订单箱数、货物重量、释放时刻 |
| \([\underline t_i^d,\overline t_i^d],[\underline t_i^p,\overline t_i^p]\) | 绝对配送窗、取箱窗 |
| \(\sigma_i,\mu_i\) | 顾客服务时长、最短使用时长 |
| \([t_0,t_1],m\) | 周期、每阶段最短时长；\(H=t_1-t_0\) |
| \(\tau_{uv},d_{uv}\) | 已给定旅行时长和距离；允许非对称、非度量矩阵 |
| \(w_0,v_0\) | 单箱重量、体积 |
| 车队参数 | 两级车辆数量、载重/容积、二级每车趟数上限、装卸及周转时长 |
| 经济参数 | 与 M8 相同的箱池、距离、工时、车辆、趟次、清洗、追踪与磨损费率 |

以下先写一个固定 \(K=k\) 的完整业务块，批集合为 \(B_k=\{1,\ldots,k\}\)。

| 变量 | 含义 |
| --- | --- |
| \(a_{cs}\in\{0,1\}\) | 顾客 c 选择仓 s |
| \(y_{ib}\in\{0,1\}\) | 订单 i 由批次 b 配送 |
| \(w_{isb}\in\{0,1\}\) | 订单 i 同时选择仓 s、批次 b |
| \(s_b,c_b,e_b\) | 批次开始、回运资格截点、批末时刻 |
| \(N\in\mathbb Z_+\) | 周期起始实体清洁箱池 |
| \(u_\rho,v_{\rho n},x_{\rho nm}\) | 趟次启用、任务访问、路径弧 |
| \(A_\rho,E_\rho,T_n,L^w_n,L^v_n\) | 趟次出发/卸回完成、服务时刻、服务后载重/容积 |
| \(U_i,h_{ib},\eta_{isb}\) | 订单空箱在所选仓卸回完成、截点累计资格、分仓分轮回运指示 |

一级任务节点为各仓的配送/回运节点，每批每辆一级车最多一趟，可只送或只取。
二级任务节点为每笔订单独立的配送/取箱任务，按仓、物理车辆和趟位建路线。
即使多笔订单的顾客坐标相同，任务仍保持独立身份。

## 目标函数

与 M8 使用同一个成本定义：

\[
\min F=p_NN+\sum_{\ell=1}^2
\left(p_\ell^D D_\ell+p_\ell^T W_\ell+
p_\ell^V V_\ell+p_\ell^R R_\ell\right)
+p^{clean}\sum_iq_i+p^{track}\sum_iq_i+p^{wear}\sum_iq_i.
\tag{9-1}
\]

\(D_\ell,W_\ell,V_\ell,R_\ell\) 分别为实际距离、含准备/装货的占用工时、
实际启用物理车辆数与实际趟数。末端完整回收使清洗箱次等于总使用箱次；
初始购箱投资另行报告，避免与已配置的箱池费用重复核算。
自由选仓会同时改变两级路线、工时、车辆启用及仓批需求，
不能只用顾客到仓的距离替代完整目标。

## 选仓与分批联动

\[
\sum_{s\in S_c}a_{cs}=1\quad(\forall c),\qquad
\sum_{b\in B_k}y_{ib}=1\quad(\forall i).
\tag{9-2}
\]

不允许的仓或批次不建立对应变量。以三条线性约束表示乘积：

\[
w_{isb}\le a_{c(i)s},\quad w_{isb}\le y_{ib},\quad
w_{isb}\ge a_{c(i)s}+y_{ib}-1.
\tag{9-3}
\]

另外加入 \(\sum_sw_{isb}=y_{ib}\)。由此，各仓各批的配送箱量和重量为：

\[
Q_{sb}=\sum_iq_iw_{isb},\qquad
G_{sb}=\sum_i(g_i+w_0q_i)w_{isb}.
\tag{9-4}
\]

这取代 M8 中按输入固定所属仓聚合的需求。每个订单的送、取任务都只允许在
\(a_{c(i)s}=1\) 的仓所属二级路线出现。配合全局任务唯一覆盖约束，
等价于在每个仓要求
\(\sum_{\rho\in\mathcal R_s^2}v_{\rho,(i,d)}
=\sum_{\rho\in\mathcal R_s^2}v_{\rho,(i,p)}=a_{c(i)s}\)。

## 日历与释放

\[
s_1=t_0,\quad e_k=t_1,\quad e_b=s_{b+1},\quad
s_b+m\le c_b\le e_b-m,
\tag{9-5}
\]

\[
y_{ib}=1\Rightarrow s_b\ge r_i,\qquad
\sum_iq_iy_{ib}\ge1\quad(\forall b).
\tag{9-6}
\]

时刻使用与 M8 相同的整数时钟。每个 k 采用
\(k/\gcd(H_{\rm ticks},k)\) 倍细分，以容纳等长特例，所有既有物理时长同步缩放；
如显式配置日历决策网格，边界及截点还须在该网格上。
绝对服务窗和释放时间不随日历优化平移。

## 路径、容量与两级衔接

每条启用路线有唯一源弧、汇弧，任务节点满足入流等于出流等于访问变量：

\[
\sum_nx_{\rho,0n}=\sum_nx_{\rho,n\omega}=u_\rho,\qquad
\sum_mx_{\rho,mn}=\sum_mx_{\rho,nm}=v_{\rho n}\le u_\rho.
\tag{9-7}
\]

每个订单的 d、p 任务在所有仓与趟次中分别恰访问一次。
一级按秩变量消除子回路；二级用严格递增的任务因果序位，
并加入 \(d_i\prec p_i\)，即使旅行或服务时长为零也不允许断开的环。
一级路线先送后取；同一订单的 p 到 d 弧不合法。

每趟的出发载荷等于本趟全部配送任务的载荷；经过配送节点减载，经过取箱节点增载。
所选弧联动载荷递推和时刻递推，例如：

\[
x_{\rho,nm}=1\Rightarrow
\left\{
\begin{aligned}
T_m&\ge T_n+\sigma_n+\tau_{nm},\\
L^w_m&=L^w_n+\epsilon_m\,weight_m,\\
L^v_m&=L^v_n+\epsilon_m\,volume_m,
\end{aligned}\right.
\quad \epsilon_d=-1,\ \epsilon_p=1.
\tag{9-8}
\]

载荷始终在该层车辆的载重/容积上下界内，首末弧另计起点旅行和返场卸货。
每趟占用时长不小于实际旅行、服务和卸货时长之和。
访问任务满足其时间窗，并满足
\(T_i^p\ge T_i^d+\sigma_i+\mu_i\)。

对每个仓 s、批 b，一级配送量之和为 \(Q_{sb}\)，至多一辆车访问该配送节点；
访问时该车承担整个 \(Q_{sb},G_{sb}\)，不能通过多辆车拆分仓批供货。
该仓供货完成 \(F_{sb}\le c_b\)。一级有配送的车在 \(s_b\) 装货，
于 \(s_b+\ell_1\) 发车；从截点后开始回运行驶，
且 \(E_\rho\le e_b\)。纯取箱车不早于截点发车。

二级一趟的配送订单来自同一批 b；若该趟在仓 s 装载 b 的货物，
则 \(A_\rho\ge F_{sb}+\ell_2\)。纯取箱趟不要求供货。
同一物理车的后趟须晚于前趟卸回完成加周转/准备时间；
一级跨批也执行同车串行。所有车须在周期末之前完成相应周转。
工时、趟数和车辆费用由这些实际启用变量计算。

## 按选定仓计算回运量

如果订单 i 的取箱任务由二级趟次 \(\rho\) 执行，令 \(U_i=E_\rho\)，
即空箱在所选前置仓卸回完成的时刻。累计资格满足：

\[
h_{ib}=1\Leftrightarrow U_i\le c_b,\quad
h_{ib}\ge h_{i,b-1},\quad h_{i0}=0,\quad h_{ik}=1.
\tag{9-9}
\]

整数时钟中，反向条件为 \(h_{ib}=0\Rightarrow U_i\ge c_b+1\)。
令 \(\eta_{isb}=a_{c(i)s}(h_{ib}-h_{i,b-1})\)，以三条线性约束实现：

\[
\eta_{isb}\le a_{c(i)s},\quad
\eta_{isb}\le h_{ib}-h_{i,b-1},\quad
\eta_{isb}\ge a_{c(i)s}+h_{ib}-h_{i,b-1}-1.
\tag{9-10}
\]

因此本轮应从仓 s 全取的空箱量是

\[
P_{sb}=\sum_iq_i\eta_{isb},\qquad
\sum_sP_{sb}\ge1\quad(\forall b).
\tag{9-11}
\]

一级在仓 s、批 b 的实际取箱量之和必须恰为 \(P_{sb}\)，且至多一车取该仓本轮箱量。
这同时约束了“取回哪个仓”和“在哪个截点回运”，不能继续按输入参考仓计算回收。

## 清洁库存与周期闭合

设一级趟次 \(\rho\) 实际回总仓量为 \(R_\rho\)，卸回完成时刻为 \(E_\rho\)，
清洗时长为 \(\gamma\)。用 \(\zeta_{\rho b}\) 标记该趟已启用且
\(E_\rho+\gamma\le s_b\)，并线性化 \(Z_{\rho b}=R_\rho\zeta_{\rho b}\)，得到：

\[
\sum_{j\le b}\sum_sQ_{sj}\le N+\sum_\rho Z_{\rho b}
\quad(\forall b),\qquad N_{\min}\le N\le N_{\max}.
\tag{9-12}
\]

可使用 \(0\le Z_{\rho b}\le R_\rho\)、\(Z_{\rho b}\le Q\zeta_{\rho b}\)、
\(Z_{\rho b}\ge R_\rho-Q(1-\zeta_{\rho b})\) 实现，其中 \(Q=\sum_iq_i\)。
有正回收量的一级趟必须满足 \(E_\rho+\gamma\le t_1\)。
全部订单完成送取、全部资格箱量被回运，再结合库存账本，保证期末全部 N 个箱子清洁在总仓。
结果必须通过从原始输入重新投影的独立路线、成本和连续两周期箱流审计。

## 将 K 也放入同一个 MILP

默认允许域为
\(\mathcal K=\{1,\ldots,\lfloor H/(2m)\rfloor\}\)，
显式子集仅证明该声明范围。引入 \(\delta_k\in\{0,1\}\)：

\[
\sum_{k\in\mathcal K}\delta_k=1,\qquad K=\sum_kk\delta_k,\qquad
\min\sum_k F_k.
\tag{9-13}
\]

每个 k 的式 (9-1)–(9-12) 按
[统一批次数 MILP](unified_batch_count_milp.md) 的零化与指示约束装配。
未选块的选仓、分批、路线和库存变量全部归零，常数费用乘对应 \(\delta_k\)。
每块只有建模，没有分别求解；完整模型只调用一次 Gurobi optimize。
选中块的 \(a_{cs}\) 就是整个方案的分仓决策。

## 与模型3、4、8的关系

固定 \(a_{cs}\) 为与 M8 一致的顾客分仓，其余物理输入、费用、日历域和资源相同，
就得到该分仓下的 M8。因此同一口径的最优成本有 \(F_9^*\le F_8^*\)。
若原 M8 输入把同一顾客的不同订单指定给不同仓，则它不满足 M4/M9 的顾客同仓规则，
须先对齐业务定义，不能直接宣称包含关系。

进一步固定 K=1、日历、批内截点、箱池，并改用 M4 的两级距离目标，
才对应 M4 的单批自由分仓问题；单独设 K=1 的 M9 仍可优化截点/箱池，
且默认直接优化完整成本，不能把两者目标值直接比较。
再固定顾客分仓可回到相应 M3 基线。
