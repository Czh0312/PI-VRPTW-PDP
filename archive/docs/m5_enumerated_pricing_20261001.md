# M5 第十三步：完整二层路线枚举与定价收敛

日期：2026-10-01。

本轮改善下界计算。保持上一轮已经完整审计的 50 顾客可行上界 **2261.8315**，新后端在 60 秒总预算内得到组合下界 **2195.3268**，gap 为 **2.9403%**；上一轮保存的组合 gap 为 9.6560%。三个种子均完成全部仓的路线覆盖 LP，总用时 20.58–22.28 秒。

这次没有改变路线覆盖松弛的数学模型。重新运行的原 MILP 定价在种子 42 上也得到接近相同的界，用时 53.38 秒；种子 43、44 在 60 秒内未收敛。收益来自完整定价更快、更稳定，并非得到了一种理论上更强的松弛。LP 收敛仍不证明完整 M5 的整数最优性。


新实现位于 [`multibatch_route_enumeration.py`](../../models/routing/solvers/exact/multibatch_route_enumeration.py)，接入 [`multibatch_route_cg.py`](../../models/routing/solvers/exact/multibatch_route_cg.py)。`pricing_backend` 默认仍是 `'milp'`，现有调用方式继续有效。

`'hybrid'` 为每个仓尝试完整路线枚举。枚举用时最多为指定上限和该仓开始时剩余预算三分之一的较小值；枚举、完整 LP 建模/求解、一级证书与必要的 MILP 回退共用原总预算。达到状态数或时间上限时，记录不完整状态并回退到原有完整 MILP 定价域，保留所有配送批次和所有回收任务。

## 2. 枚举范围与安全剪枝

每条二层路线按配送批次分类，另有纯回收类别。一趟至多服务一个配送批次，但可以回收所有批次的订单。每项配送/回收任务至多访问一次，允许相同物理位置重复出现。访问顺序使用原始有向距离和整数行驶时间，不要求三角不等式。

深度优先搜索检查服务窗口、同趟配送先于回收、订单最短使用时长、重量和体积。当前路径的初始载荷包含该路径中所有配送任务，包括位于后面的配送。增加未来配送只会提高此前各位置的载荷，因此超容量的前缀可以安全剪除。

回仓剪枝使用最短行驶时间下界。原始直接回仓弧可能比绕行慢，不能据此排除仍可继续访问其他任务的路径；直接回仓只用于判断当前路径能否成为完整列。包含回收的路线必须在最后回收截止前卸箱完成；纯配送路线可以在该截止之后返回，但仍须满足周期终点和周转时间。

搜索穷尽后，每个**任务集合**只保留成本最低的可行顺序。路线覆盖 LP 的覆盖系数、有限总趟数系数以及对偶定价只依赖任务集合，故较贵的同集合路线被严格支配。这一规则仅适用于当前松弛，不能直接用于保留真实供应、清洗和车辆串行时间的完整 M5 整数主问题。

## 3. 完整 LP 与下界口径

完整枚举成功后，直接建立包含全部保留列的连续路线覆盖主问题：每项任务恰好覆盖一次，路线数不超过有限车队和最大趟数推导的总上限 (K)。变量是连续的非负路线使用量。

对完整路线域重新计算最小约化成本，而非只检查 LP 中正值列。沿用已有保守对偶证书：

\[
L_s=\sum_t\pi_t+K\nu+K\min(0,\rho),\qquad \nu\leq0.
\]

其中 \(\rho\) 是完整路线域最小约化成本减去数值余量。一级证书与各仓二层成本界相加，再与原距离证书比较，得到完整 M5 的有效成本下界。浮点余量使新后端的界可能比已收敛原定价低约千分之一，本次差异不代表松弛模型不同。

诊断导出包括完整路线域 `*_best_pricing.json.gz` 和包含全部列的 `*_best_pricing_master.mps.gz`。结果 JSON 只保留正值 LP 列以控制体积，`columns_generated` 和 `variables` 记录完整列数；不能把结果 JSON 中的正值列数误认为完整路线域大小。

完整模型的 `proven_optimal`、`proven_infeasible` 继续为 `False`。`LP_CONVERGED` 只表示对应松弛的 LP 已完成；完整枚举失败后的部分列不提供定价下界。

最终复核记录见 [validation.json](../../output/experiments/m5_enumerated_pricing_20261001/validation.json)，本轮定向代码改动见 [changes.patch](../../output/experiments/m5_enumerated_pricing_20261001/changes.patch)。正式实验冻结后，共享代码另增加了默认 `'auto'` 的一级后端选择参数；复核记录两份源码哈希及逐项差异，二层枚举实现未变，并另跑了当前入口的定向回归。

最终复核通过全部 **34** 次正式运行，重新求解 **45** 份完整二层 LP 和 **34** 份一级模型，累计重放 **931,377** 条完整 LP 列并检查 **1,005** 份对偶证书；去重后的 **25** 个仓级路线域均与独立前缀重枚举的最低成本集合完全一致。

## 7. 剩余 gap

新后端下界与现有可行上界相差约 **66.50**。各仓原有路线覆盖 LP 已闭合，继续延长同一松弛的定价时间，预期不能实质提高其 LP 目标。

下一步应检查完整路线覆盖的整数下界，以及主问题中实际供应、回收截止、清洗和物理车辆串行的连接。加强这些连接可以缩小现有松弛；完整精确求解仍需保留完整路线域及有效分支/证明口径。更大实例的路线域可能迅速增长，因此保留状态/时间上限与完整 MILP 回退。
