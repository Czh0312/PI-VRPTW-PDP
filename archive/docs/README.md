# 历次算法实验导读

本目录收纳已结束的逐轮开发、诊断及旧基线记录，供追溯采用、撤回和局限；不作为当前计划。文中“最新”“本轮”等表述对应各报告日期；当前入口见[文档导航](../../docs/README.md)，完整结果见[结果目录](../../output/README.md)。

## 单批次精确求解

单批次 M1/M2 的根节点列生成下界、标签/MILP 精确定价及等总预算混合求解试验，见
[列生成原型与证明边界](single_batch_columns_20261001.md)。该原型只在显式实验入口启用。
利用列生成路线池构造可行初解的后续优化，见 [路线池排程与同预算对照](single_batch_route_pool_20261001.md)。
后续[时间必要条件与分仓对偶约束试验](single_batch_dual_cuts_20261001.md)记录下界强化、退步方案和同预算验证。
[批量定价效率试验](single_batch_pricing_pool_20261001.md)继续检查根节点提速能否改善端到端精确求解。
[一级货流汇总试验](single_batch_compact_pool_20261001.md)进一步缩小 M1/M2 初解路线池，并保留同池速度退步的对照结果。
[热启动排程整理试验](single_batch_start_20261001.md)验证同质车辆编号和最早排程，尚未测得稳定提速，保留显式实验选项。
[路线池时间约束试验](single_batch_pool_bounds_20261001.md)收紧供货与多趟时间界，并合并每个车辆位置的时间约束，保留各版本的完整对照结果。
[定价时间分解试验](single_batch_pricing_schedule_20261001.md)修复空窗口任务的子问题处理，比较连续时钟与按需时间禁用约束，并验证每条禁用约束的有效性。
[路线池车辆排序试验](single_batch_pool_symmetry_20261001.md)进一步检查同质车辆搜索对称性，保留分数解反例、两版实现及同预算对照。
[完整整数模型二环与次序边界试验](single_batch_causal_bounds_20261001.md)覆盖 M1–M4，记录两个有效但未测得稳定提速的候选和 30 客户 M4 补测。
[夜间标签定价下界试验](single_batch_label_bound_20261002.md)记录返仓下界、批量发现两版实现、定价搜索减少及端到端退步，候选默认关闭。
[固定初解与对偶约束消融](single_batch_certificate_ablation_20261002.md)以三种子分离约束集合影响，并独立核查全部保留平面；属于离线诊断，不作默认采用。

## 单批次 ALNS

单批次 M1–M4 的修复顺序、周期重启及上下文复用试验，见
[修复与重启优化记录](alns_single_batch_repair_20261001.md)，含完整退步、撤回门槛与最终回归。
下降邻域的车辆就绪与显式等待筛选修正，见
[筛选修正与大规模验证](alns_single_batch_readiness_20261001.md)，含确定性漏搜反例、质量波动与耗时代价。
后续[regret修复试验](alns_single_batch_regret_20261001.md)已撤回；
[M3下降邻域距离缓存](alns_single_batch_descent_cache_20261001.md)通过另两来源的固定工作量复核与等时质量检查，已保留。
后续[M3修复阶段距离缓存](alns_single_batch_repair_geometry_20261001.md)记录两个撤回候选及M3单独确认，保留通过验证的M3提速。
已采用[单批次静态载荷摘要复用](alns_single_batch_load_cache_20261001.md)降低M1–M4完整解码开销，并记录逐模型质量波动及验证结果。
后续[M3早期成对交换](alns_single_batch_exchange_20261001.md)与[零罚项快速分支](alns_single_batch_penalty_fastpath_20261001.md)均因等时质量退步撤回，保留前述求解实现及完整试验记录。
最新[M3回收插入前缀复用](alns_single_batch_lazy_pickup_20261001.md)通过CPU与等时质量验证，含三项撤回原型、全部退步和四模型复现结果。
本轮[四项续试与撤回记录](alns_single_batch_continued_attempts_20261001.md)保留未达双来源CPU门槛的方案和恢复版本验证；没有新增采用的优化。
后续[静态准备与M2成组换仓试验](alns_single_batch_route_groups_20261001.md)记录短预算改善但长预算未通过的两版搜索策略及全部撤回结果。
本次[M2容量约束尾段重组](alns_single_batch_route_recombine_20261001.md)在长预算试验改善、短预算未通过，候选已撤回；输入加载故障和补充实验单独记录。
后续[M2审计热启动与末尾下降](alns_single_batch_audited_route_descent_20261001.md)均因长预算未通过撤回，含有效候选稀疏的诊断、全部32次质量运行和恢复版验证。

[M5 GAP 第六轮](model5_gap_round6_20261001.md)，含全部暖启动追加预算与 181 项回归；尚未验证从头同预算稳定达标。
自动多批供货组合和候选上限已接入统一入口，全池最好认证 GAP 降至 **3.04%**；660 秒冷启动对照为 23.57% / 21.65%，见
[M5 GAP 第七轮](model5_gap_round7_20261001.md)，含独立证书投影、188 项回归和完整未达标结果。
