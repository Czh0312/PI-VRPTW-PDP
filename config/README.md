# 参数目录

参数按照用途分层保存，避免理论算例、真实案例、算法调参与经济成本相互混用。

- `routing/validation/`：理论与基准算例使用的车辆、容量、速度和容器物理参数。
- `routing/real_cases/`：真实场景车辆参数；必须注明单位以及观测值/情景假设口径。
- `cost/cases/`：包装、清洗、损耗、运输单价及成本分析周期。
- `algorithms/`：ALNS、精确求解等算法预算和调参值。
- `cases/`：案例清单，只负责组合数据、矩阵及上述参数文件。

正式运行时优先选择一个 `cases/*.json`，不应在入口代码中手工拼接多个参数文件。
