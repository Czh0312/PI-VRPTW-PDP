## 二、并列机制的经济价值

- 每期配送容器：**235 个**；回收容器：**230 个**。
- 包装替代毛收益：**546.17 元/期**。
- M1 → M3 闭环回收运输增量：**76.06 元/期**。
- M3 → M4 自由分配收益：**38.69 元/期**。
- 独立运行 M3 − M6 路线成本差：**-0.95 元/期**；该值混有第一阶段普通 ALNS 差异，不作为中转收益。
- 扩展预算三种子验证中的同次运行中转直接收益均为 **0.00 元/期**；详见 `output/m6_transshipment_validation_lade_real_0829/`。
- M4 − M6 运输成本差：**-39.65 元/期**（正值表示 M6 更低）。
- 采用 Model 4 后净边际收益：**508.81 元/期**。
- 初始容器池投资：**32,850.00 元**。
- 回本周期：**64.56 期**；累计使用约 **15,172 次**。
- 临界一次性包装购置价：**1.83 元/个**。
- 临界业务密度：**16.08 个容器/期**（路线不变且车辆容量可行时）。

恒等式：`净边际收益 = 包装替代毛收益 − M1→M3闭环运输增量 + M3→所选Model 4路径收益`。

## 四、论文解释

Model 4 与 Model 6 都是从 Model 3 扩展出的并列优化机制，不能解释为连续的 M3→M4→M6 改进链。结果应分别报告自由分配与异步交接/路径机制的观测收益；限时 ALNS 值是同预算可行解，不是模型全局最优证明。
