## 二、扩展机制的经济价值

- 每期配送容器：**235 个**；回收容器：**230 个**。
- 包装替代毛收益：**546.17 元/期**。
- M1 → M2 一次性侧自由分仓收益：**86.59 元/期**。
- 固定分仓 M1 → M3 闭环回收运输增量：**64.07 元/期**。
- 自由分仓 M2 → M4 闭环回收运输增量：**140.28 元/期**。
- M3 → M4 循环箱侧自由分仓收益：**10.37 元/期**。
- M3 → M6 固定分仓异步交接收益：**0.00 元/期**。M6 直接继承本次 M3 解，因此该差额与同次运行中转收益一致。
- M4 → M7 自由分仓异步交接收益：**0.00 元/期**。M7 直接继承本次 M4 解，因此该差额与同次运行中转收益一致。
- M6 同次运行中转直接收益：**0.00 元/期**，中转 **0 次**。
- M7 同次运行中转直接收益：**0.00 元/期**，中转 **0 次**。
- 采用 Model 4 后净边际收益：**405.89 元/期**。
- 初始容器池投资：**32,850.00 元**。
- 回本周期：**80.93 期**；累计使用约 **19,019 次**。
- 临界一次性包装购置价：**2.27 元/个**。

价值分解采用与一次性侧相同分仓自由度的循环基准 Model 4。恒等式：`净边际收益 = 包装替代毛收益 − 所选一次性Model 2→参考循环Model 4运输增量 + 参考循环Model 4→所选循环Model 4路径收益`。

## 四、论文解释

Model 2/4 分别测量一次性侧和循环箱侧的自由分仓价值；Model 6 是 Model 3 的固定分仓异步交接扩展；Model 7 是 Model 4 的自由分仓与异步交接联合扩展。纯中转收益只能取同一次 M6/M7 运行内部的阶段一与最终值之差，不能用独立 ALNS 结果相减。
