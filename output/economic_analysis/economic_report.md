**结论：可循环容器具备回本条件。**

同一数据、同一距离与时间口径、seed=42、每模型 5 秒预算下，在已测试的 Model 3、Model 4 和 Model 6 路线中，经济测算采用运输成本最低的 Model 4。这是限时 ALNS 的阶段性结果，不代表所有模型的全局最优。

- 每期配送容器：**7 个**；回收容器：**7 个**。
- 包装替代毛收益：**16.13 元/期**。
- M1 → M3 闭环回收运输增量：**180.02 元/期**。
- M3 → M4 自由分配收益：**244.33 元/期**。
- 独立运行 M3 − M6 路线成本差：**0.00 元/期**；该值混有第一阶段普通 ALNS 差异，不作为中转收益。
- M4 − M6 运输成本差：**-244.33 元/期**（正值表示 M6 更低）。
- 采用 Model 4 后净边际收益：**80.45 元/期**。
- 初始容器池投资：**3,650.00 元**。
- 回本周期：**45.37 期**；累计使用约 **318 次**。
- 临界一次性包装购置价：**-7.49 元/个**。
- 临界业务密度：**0.00 个容器/期**（路线不变且车辆容量可行时）。

恒等式：`净边际收益 = 包装替代毛收益 − M1→M3闭环运输增量 + M3→所选Model 4路径收益`。

## 四、论文解释

Model 4 与 Model 6 都是从 Model 3 扩展出的并列优化机制，不能解释为连续的 M3→M4→M6 改进链。结果应分别报告自由分配与异步交接/路径机制的观测收益；限时 ALNS 值是同预算可行解，不是模型全局最优证明。

## 五、口径限制

- 距离口径：Zhou/Solomon-style coordinate units are provisionally treated as kilometers. This is an operating assumption, so absolute currency results require a real-kilometer dataset or a calibrated scale; relative route savings remain valid.；换算系数为 1.0。
- 成本曲线把同一代表性路线按期重复，用于回本分析，不代表扩展客户规模。
- 清洗、损耗率和容器池规模是运营假设，需结合敏感性结果报告。
- 若坐标并非真实公里，绝对金额仅是情景测算；相对路径收益仍然有效。
