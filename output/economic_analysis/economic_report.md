# 可循环容器经济性与路径优化价值报告

**结论：可循环容器在基准参数下尚不具备回本条件。**

## 二、经济价值来自哪里

- 每期容器使用量：**7 个**。
- 包装替代毛收益：**16.13 元/期**。
- 闭环回收运输增量：**180.02 元/期**。
- Model 6 相对 Model 3 的路径优化收益：**0.00 元/期**。
- 优化后净边际收益：**-163.89 元/期**。
- 初始容器池投资：**3,650.00 元**。
- 回本周期：**无（当前参数下边际收益≤0） 期**；累计使用约 **无（当前参数下边际收益≤0） 次**。
- 临界一次性包装购置价：**27.41 元/个**。
- 临界业务密度：**78.10 个容器/期**（路线不变且车辆容量可行时）。

恒等式：`净边际收益 = 包装替代毛收益 − 闭环回收运输增量 + 路径优化收益`。

## 四、论文解释

结果应同时报告包装替代的材料价值和路径优化降低逆向物流成本的运营价值。即使基准场景未回本，临界包装价格、临界业务密度和敏感性情景也能说明循环箱在什么条件下具有经济性，不能为了得到正结论而调整参数。

## 五、口径限制

- 距离换算：Zhou/Solomon-style coordinate units are provisionally treated as kilometers. This is an operating assumption, so absolute currency results require a real-kilometer dataset or a calibrated scale; relative route savings remain valid.；系数为 1.0 km/坐标单位。
- 成本曲线把同一代表性路线按期重复，用于回本分析，不代表扩展客户规模。
- 清洗、损耗率和容器池规模是运营假设，需结合敏感性结果报告。
- 若坐标并非真实公里，绝对金额仅是情景测算；相对路径收益仍然有效。
