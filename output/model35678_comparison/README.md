## 此前重新搜索的实验

以下实验使用原距离单价和原磨损单价：一级、二级运输均不计算占用时间费、每辆车固定费和每趟固定费。距离费、箱池费、清洗费、追踪费和磨损费保留。

- [新成本口径下重新搜索的六例对比](20261006_distance_pool_5min_v1/report.md)：六个 50/100 点算例、五个模型、每次 ALNS 300 秒、seed=42。输入、运行方案、双周期独立审计、费用明细和冻结源码均归档。
- [同一批旧方案按新价格重新计价](20261006_5min_v1/reprice_distance_pool_v1/report.md)：仅重新计价，不等于新目标下重新优化。新搜索报告使用它作为同价配对参考。
- [原成本口径下的五分钟运行](20261006_5min_v1/report.md)：包含工时、车辆和趟次费用的历史结果。
- [原费用差额归因](20261006_5min_v1/cost_analysis/report.md)：说明原距离目标基准与联合模型之间的出发时刻处理差异。工时费归零后，该处理差异不再直接产生费用收益。

清洗费按每次实际回总仓的容器箱次累计，同一物理箱子再次使用、回库需要再次计费。周期末最后一轮回库也计费。独立箱池数量 N 与周期需求箱次 Q 必须分开：前者决定箱池费，后者在完整回收时决定清洗、追踪和磨损总费用。

模型 3、5保留距离优化和配置箱池；模型 6、7、8直接优化新的周期成本，并采用优化得到的箱池数量。报告另外给出模型 3、5原时间表的最低箱池计价参考，不能将其误称为箱池优化输出。

价格均为合成成本单位。此前原价格实验完整回收情况下 `C = 一级距离 + 二级距离 + 5N + 0.5Q`；最新清洗0.2参数为 `C = 2.535D1 + 0.056470588D2 + 5N + 0.4Q`。实际配送批次与日历段数 K 分别报告；有空日历段不代表发生了容器循环利用。

## 复核和重新运行

在仓库根目录运行：

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
python output/model35678_comparison/20261006_distance_pool_5min_v1/verify_and_report.py
# 复核最新参数重新搜索的结果
python output/model35678_comparison/20261006_truck_tricycle_5min_v2/verify_and_report.py
```

复核程序支持仓库迁移目录，验证冻结文件哈希，重新审计最终方案并重算成本。需要 Python 项目依赖，以及报告绘图使用的 matplotlib、numpy。

重新搜索应将相应实验的 run_study.py、monitor_study.py、verify_and_report.py（最新实验还需report_content.py）复制到 `output/model35678_comparison/` 下另一个空目录，然后运行该目录的 run_study.py。每轮注册并冻结输入及代码，已有目录拒绝覆盖。运行后执行 verify_and_report.py 导出详细报告和图。

本轮使用一个随机种子和有限搜索预算。即便价格和种子相同，机器竞争与时间截止也可能改变搜索轨迹；结果不是全局最优证明。
