## 完成后必须生成的证据

1. 在同一 N 横坐标上并列原日程可行性与重新优化首次调用状态；不将缺失/未解记为零费用。费用图单独保留总费用、池费、两级运输费和占用费，固定日程费用仅在其可行 N 上由原独立物理审计重计。路径、服务时刻和截点完全不变，池费变化不解释为路线改进。
2. 每例阈值结论必须同时记录必要下界、各更小整数的排除证据及可行上界见证。限时未解留下未决整数，不能合并到不可行。已有固定日程的可行见证可以作为上界证据，但与正式重新优化调用的成功率分开。
3. 每例在最小已审计可行 N 处画两周期箱流与清洗释放时间线。选取该点最小编号的有效种子，不按最低费用选择；全部无解时写明没有时间线见证。沿用最早首次尝试，不以重试替换。图表标签必须含案例、N、种子、方法和证明状态。
4. 将 reference minimum、重新优化可行上界和已证阈值分列；差值只有在参照匹配、证据充分时才能解释。中大例只有一个 N，报告固定分批造成的边界情况与有限时间搜索表现。
