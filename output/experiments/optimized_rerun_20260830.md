## 4. 是否还需要优化

需要，但重点已经从“可用性”转到“继承和证明质量”：

1. **M7 精确求解 warm start**：应直接注入已验证 M4 incumbent，或使用自适应 M4 预算，而不是仅依赖 60 秒内部直解。验收条件应为每个限时实例 `M7 incumbent ≤ 已知 M4 incumbent`。
2. **独立 ALNS 的嵌套 incumbent**：当前六模型独立从头搜索，因此理论扩展关系在有限时间下并不自动成立。共同实例中 `M2≤M1` 仅 1/17、`M4≤M3` 仅 5/17、`M7≤M4` 仅 6/18。正式比较应同时报告独立搜索和嵌套 warm-start 搜索。
3. **固定分配难例诊断**：为 M1/M3/M6 增加失败原因分类与可行性修复，判断 `Set2_200-10-3` 是构造器不足、车队/时间窗冲突，还是固定分配本身不可行。
4. **统计稳健性**：对 ALNS 至少补做 5 个随机种子，报告均值、标准差和最佳值；当前 seed=42 适合回归比较，但不足以独立支持算法优劣的统计结论。
