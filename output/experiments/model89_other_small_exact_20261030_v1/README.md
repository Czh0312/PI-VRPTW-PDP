# M8/M9新增小规模S03、S04精确对照

本轮使用现有统一7/20/50数据集的S03、S04，各7客户、2前置仓，均使用单一种子42。
原始网络、订单、车辆、费率、箱池范围和秒级时间域保持原样；输入与源码哈希配对检查通过。
每次求解300秒、单线程、等价compact表达，无外部初解。两算例并行，至多同时两次单线程求解。
本轮没有改动求解器。所记录时间受到并行负载影响，不据此作严格速度比结论。
