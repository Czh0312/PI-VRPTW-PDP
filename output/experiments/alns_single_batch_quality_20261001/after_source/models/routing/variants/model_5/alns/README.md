# M5：ALNS 求解

`solver.py` 是本模型的独立入口，调用 `../../../solvers/alns/` 下的共用实现。
不依赖精确求解或 Gurobi；可行解不声明全局最优。

多批次搜索包含有界的距离下降邻域：二级任务移动、整笔送取请求迁移/交换、路线反转，
以及一级配送仓点移动/交换和回收安排。候选仍须完整重算截止回收、清洗库存、车辆复用，
只有独立审计通过的方案才能更新最好解。该扩展仅在 B>1 启用。

搜索前段采用固定辅助种子 0，达到总时间的 40%、600 次迭代或总迭代上限的三分之一时切换
至用户指定的随机种子。该前段计入同一个时间/迭代预算；单个候选计算和最终审计可能带来少量预算超时。
后续搜索保留可行最好解，并周期性从最好解继续破坏/修复。

结果 `info` 新增初解目标、逐次最好解轨迹、共同搜索阶段迭代数和邻域诊断。
种子间波动是该完整算法的波动，包含共享初始搜索阶段；不代表从独立随机初解开始的实验。
算法效果及所有改善/退步见 [M5 优化记录](../../../../../docs/model5_alns_optimization_20260930.md)。

一级回收方案现在按全部批次的配送、回收次序、车辆提示和归属数量缓存；
二级距离邻域只重新枚举任务次序发生变化的卫星仓。时序、回收归属和库存仍重新检查，
诊断增加 `e1_schedule_cache_hits/misses` 与 `descent_site_cache_hits`。
`descent_enumerations` 现在按实际重新枚举的仓内状态计数，不能直接与旧版整轮枚举次数比较。
