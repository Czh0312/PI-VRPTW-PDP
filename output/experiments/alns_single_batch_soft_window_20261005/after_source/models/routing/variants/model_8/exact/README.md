# 模型8精确求解

入口：`solver.solve_exact`。模型构建：`model.build_model(problem, batch_count=K)`。外层枚举配置K，并在一次调用的总时间预算内求解各K。

每个K包含K−1个内部整数边界变量和K个独立整数截点变量。每批两阶段至少满足输入最短时长；批次连续覆盖整个周期。边界直接参与释放、回运、清洗释放、库存和车辆约束。复用模型6的路线和成本MILP内核，独立于ALNS。M8不枚举候选长度或借用启发式方案限定精确域。

只有所有配置K均证明最优或不可行，才报告全域最优。限时、无可行解和证明不可行分别保存。提取后独立重建日历并执行成本及两周期物理审计。
