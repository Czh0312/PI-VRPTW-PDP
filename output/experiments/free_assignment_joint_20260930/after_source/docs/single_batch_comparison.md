# 单批次四模型与条件经济性

2026-09-29 更新。策略为 `multi_batch_cutoff_v1`，本页说明 B=1 的新增实现。
代码与机制已验证；本页的经济推导是给定路线和参数下的条件结论，尚无真实闭环经营数据支持实际盈利结论。

| 模型 | 包装 | 顾客分仓 | 当前算法 |
| --- | --- | --- | --- |
| M1 | 一次性，纯配送 | 输入固定 | 联合 MILP / ALNS |
| M2 | 一次性，纯配送 | 每个顾客可选择一个仓 | 联合分仓 MILP 或枚举 / 分仓搜索＋ALNS |
| M3 | 循环，配送和延后回收 | 输入固定 | 联合 MILP / ALNS |
| M4 | 循环，配送和延后回收 | 每个顾客可选择一个仓 | 联合分仓 MILP 或枚举 / 分仓搜索＋ALNS |

包装经济性按 M1/M3、M2/M4 比较。分仓价值按 M1/M2、M3/M4 比较。
B>1 由独立编号的 M5 负责，当前为固定分仓。旧模型在 `models/routing/baselines/`，不参与这些比较。

## 共同规则与包装差异

四模型读取相同网络、订单、时间窗、车辆、容量和 B=1 日程。配送服务须在唯一批次的截止前完成；
一级每车一趟，二级可在给定趟次上限内复用物理车辆。当前假定两种包装正向运输时重量、体积相同，
这是一项比较假设，尚未按实际包装规格校准。

M1/M2 只产生配送任务，不要求顾客交回一次性包装，不占用循环箱池，也不计清洗和循环箱追踪费。
每次重复运营都重新购买一次性包装。输入保留共同订单的回收字段，但不把回收可行性施加给一次性方案。
车辆必须在大周期末可用；两周期审计对一次性方案验证车辆和配送服务，而非容器闭环。

M3/M4 必须在截止前将全部空箱卸回前置仓，再按截止全取规则回总仓，完成清洗，恢复全部清洁箱池。
单批次没有后续批次可复用，因此 N 至少为全周期箱次 Q；经济上的复用来自多个完整大周期的重复运营。
M2/M4 对同一顾客的所有订单保持同一分仓，配送与回收均使用该仓，不拆分订单。

各模型的时间表独立重放并核对数量、车队占用、容量、供货、服务窗口与周期边界。
B=1 在审计通过后，对固定路线、车辆和访问顺序计算最早可行时间表，再次独立审计。
这一约定去掉距离 MILP 的任意时间松弛，不改变路线和距离，也不保证工时最小。
成本中的工时是车辆占用工时，含声明的准备、装卸和等待。

## 最优性范围

M1/M3 的精确解来自当前车辆索引 MILP。M2/M4 按展开规模使用联合顾客分仓 MILP，较大模型保留完整枚举。
联合模型证明最优且方案审计通过，或全部枚举组合被最优、不可行证明或有效成本界闭合，才能报告全局距离最优。
`assignment_strategy` 区分联合求解与枚举；`assignments_visited` 仅统计枚举，联合求解中该值为 0，不能理解为没有搜索。
`assignments_closed`、`assignment_count` 保存全局闭合进度；枚举后端另有 `subproblems`。
未访问组合采用覆盖全部合法分仓的保守距离下界；部分子问题超时不能成为全局最优或不可行证明。

分仓组合数量为“仓数的顾客数次方”，精确枚举仅适合很小的验证算例。
自由分仓启发式交替尝试初始分仓、最近仓及顾客迁移/交换，在固定分仓内运行 ALNS。
它可能在同预算下劣于固定分仓单次搜索，不保证找到全局最好分仓，不声称具有大规模性能优势。
精确最优性也仅适用于声明的整数时间精度、车队和趟次上限。

## 经济关系

对同一需求和服务范围，通过审计后核算：距离费用、车辆占用工时费用、实际启用车辆费用。
这三项费率必须表示互不重复的成本组成。循环方案另计按实际箱次计算的清洗、追踪；
一次性方案另计每个周期的包装购买和处理费用。

定义：

- Q：每个周期配送包装数量；N：循环箱池规模。
- p：一次性包装单价；d：单件一次性包装处理费。
- A：一次性方案每周期运输、工时及车辆费用。
- R：循环方案每周期运营费用，含运输、工时、车辆、清洗及追踪，但不含箱池购买。
- I=N×循环箱单价；L：箱池整批更新间隔，单位为完整大周期；T：评价周期数。

在订单与服务每周期相同、无随机损耗、无折现/融资/通胀/残值、每 L 周期整池更新的假设下：

```text
一次性每周期费用 S = A + Q(p+d)
一次性累计费用     = T·S
循环累计费用       = T·R + I·ceil(T/L)
循环累计节省       = T(S−R) − I·ceil(T/L)
```

所以，给定这些方案和参数，循环方案在 T 周期内不更贵，当且仅当最后一式非负。
这是可核验的条件，不预设结果必为正。初始投入包含在整池购买次数中，不再额外叠加摊销。
每个完整寿命块内不更贵的条件为 `L(S−R) >= I`；Q>0 时可写成一次性包装单价阈值：

```text
p >= (R + I/L − A)/Q − d
```

该阈值针对固定方案的寿命平均费用，不能直接解释为任意中途时点都已回本。
报告逐周期列出现金累计差额，分别记录首次回本、此后直到评价期末不再亏损的起点。
寿命到期后的补购可能使已回本方案再次出现负差额；评价期内没有回本时明确记为 null/None。

距离最优路线的费用后处理不等于费用最优。相同最优距离也可能对应不同车辆数和工时，
本实现保留所求方案并统一时间约定，不声称所有距离最优方案经济性相同。
费用和寿命网格是固定路线上的敏感性分析；改变这些参数不触发路线重新优化。

## 运行与产物

```sh
# Zhou 15 个 B=1 案例，预览 M1–M4 共 60 项任务，不实际求解
.venv/bin/python experiments/runs/run_single_batch_exact.py \
  --source-kinds zhou_derived_scenario --exact-time 300 --seed 42 --workers 2 --dry-run

# 一个案例，四模型，一个精确参考、三个 ALNS 种子；费用参数为虚构演示
.venv/bin/python main.py compare-single-batch \
  --case config/cases/single_batch_demo.json \
  --solver both --seeds 42 43 44 --time 1 --exact-time 10 \
  --economic-config config/cost/cases/single_batch_synthetic.json

# 单独运行新版自由分仓循环方案
.venv/bin/python main.py route --model 4 --solver alns --time 2

# 单独核算已保存的一次性方案；模型必须与保存结果匹配
.venv/bin/python main.py cost --model 1 --route-result /path/to/result.json \
  --economic-config config/cost/cases/single_batch_synthetic.json
```

`run_single_batch_exact.py` 按 `batch_count=1` 选择所有来源和规模的案例，只运行 M1–M4 的精确求解。
运行前统一冻结输入和源码；`--dry-run` 可检查任务矩阵，`--families`、`--sizes` 可缩小范围。
每项预算包含建模与求解；M2/M4 的预算覆盖联合模型、热启动或整个分仓枚举。两项并发时，每个求解器仍使用单线程。
`progress.json`、`runs.csv` 与 `report.md` 随运行更新，分别保留已证明最优、可行未证最优、
已证明不可行、时限内无解和异常状态。全量精确运行不自动追加 ALNS 或经济分析。

批量入口只接受 B=1，每个方法/种子单独输出经济对照，不择优挑选运行结果。
运行前冻结全部输入、参数、执行源码和预算；子进程外层时间限制为求解预算加 `--timeout-overhead`。
失败、未找到解、超时和异常均保留，缺少双方审计合格方案的配对不产生经济数字。
拒绝覆盖非空结果目录。

| 产物 | 用途 |
| --- | --- |
| `manifest.json`、`inputs/`、`source_snapshot/` | 来源哈希、参数、运行矩阵和冻结副本 |
| `case_M1.json` 至 `case_M4.json` | 相同输入的四个模型配置 |
| `runs.csv`、每次运行 `result.json` | 全部运行状态、证明、路线、日程与独立审计 |
| `comparison_<solver>_seed<seed>.json` | 成本组成、逐周期累计费用、回本状态、价格/寿命敏感性 |
| `report.md` | 四模型和各对照结果汇总 |

## 已有验证与研究缺口

[机制对照报告](../output/experiments/single_batch_comparison_v1/validation_20260929/report.md)：
四模型精确解均证明距离最优，M1/M2 为 17.656854，M3/M4 为 20；三个 ALNS 种子也达到这些距离。
16 次运行均通过审计及两周期重放。虚构费率下，一次性每周期费用 110.790188，循环运营费用 130.6，
初始箱池投入 60；寿命 10 周期、评价 30 周期时，循环累计多花 774.294373 个演示单位，没有回本。
价格 1/5/10/15、寿命 5/10/20 的全部组合均保留，用于展示经济结果的条件性。
该小例中自由分仓与固定分仓最优距离相同；另有回归例证明自由分仓可修复固定分仓的时间窗不可行。

还运行了 [Zhou 10 顾客派生例](../output/experiments/single_batch_comparison_v1/zhou_Set1_10-2-1_20260929/report.md)
与 [LaDe 10 AOI 派生例](../output/experiments/single_batch_comparison_v1/lade_0823_10aoi_20260929/report.md)：
每例四模型、ALNS 三个种子，每次预算 2 秒，共 24 次运行，全部通过独立审计和两周期重放。
加机制例合计 40 次有效运行。派生例没有精确最优证书；部分自由分仓启发式结果劣于固定分仓结果，
说明当前短预算搜索尚不能稳定体现自由分仓的潜在优势，不能将这些差值当作模型可行域的理论排序。

全库回归 201 项通过，另重新审计原有 207 个 B1/B2/B3 时间表，全部保持有效且两周期重放通过。
这些是实现验收，不能替代预先确定样本、预算和统计方法的正式算法评测。

完整真实闭环数据仍缺失。LaDe 派生的配送需求与道路矩阵已保留，但容器交回、清洗、损耗、寿命和费用
尚需实际观测或可核查参数；[数据状态](data_status.md)列明本机缺失的 raw 文件和仍属情景的字段。
当前提供的是可重现的单批对照与条件经济分析链路，尚未证明真实企业的盈利、最优箱池或最优费用。
