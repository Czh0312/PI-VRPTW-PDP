# 大规模 M3 / M4 / M6 / M7 ALNS 对比

标准同日回收场景，18 个实例、seed=42/43/44、每次 3 秒、迭代上限 1,000,000。四个模型使用相同实例和 seed；M6/M7 的中继统计是实际触发次数。

| 模型 | 可行率 | 平均距离 | 平均运行时间 | 触发中继 | 平均中继改善 |
| --- | ---: | ---: | ---: | ---: | ---: |
| M3 | 51/54 | 2015.3074 | 2.856s | 0 | 0.0000 |
| M4 | 54/54 | 2072.7527 | 3.044s | 0 | 0.0000 |
| M6 | 51/54 | 2072.0420 | 2.790s | 15 | 1.5210 |
| M7 | 54/54 | 2102.5165 | 2.905s | 42 | 9.2358 |

配对改善率按共同可行的实例与 seed 计算，正数表示后一个模型距离更短。

| 比较 | 配对数 | 平均改善率 | 后者胜/平/负 |
| --- | ---: | ---: | --- |
| M3 → M4 | 51 | 0.462% | 18/0/33 |
| M3 → M6 | 51 | -2.778% | 7/0/44 |
| M3 → M7 | 51 | -1.082% | 12/0/39 |
| M4 → M6 | 51 | -5.194% | 29/0/22 |
| M4 → M7 | 54 | -1.628% | 18/0/36 |
| M6 → M7 | 51 | 1.596% | 17/0/34 |

解释：这些是短预算 ALNS 结果，不是全局最优性证明。M4/M7 的自由分仓和 M6/M7 的中继会分走搜索时间，因此最终距离同时反映机制和时间分配。M7 中继改善是相对其自身交接前解，不能直接当作相对 M4 的改善。

最大路线距离复算误差：2.27e-12。
