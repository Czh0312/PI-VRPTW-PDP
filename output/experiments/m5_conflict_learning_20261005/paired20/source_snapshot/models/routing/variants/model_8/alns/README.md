# 模型8 ALNS

入口：`solver.solve_alns`。所有K共享总时间与迭代预算，不导入Gurobi或精确后端。

search.py联合搜索批次边界、独立截点、订单分批和路线。新增shift_boundary、align_boundary、redistribute_lengths算子，日历变动后重新筛选合法批次并修复订单和路线。算子权重自适应更新，使用模拟退火接受和最优解重启；事件种子可跨越均匀日历的备货释放障碍。

每个可行方案独立核验库存、清洗、车辆和成本；不把启发式无解当作不可行证明。同模型已保存起点重新审计后保留，最优证明不会继承。有限预算下不保证达到精确最优值。
