# 模型6精确求解

均匀周期基础版：`schedule_mode=uniform_cycle` 逐一枚举配置K，周期均分为K批；每个MILP只使用一个整数 `shared_cutoff_offset`，所有批次c_b=s_b+d。订单、容器池、两级路线仍在该MILP中联合优化。各K共享一次调用的总时间预算。`count_search`保存每个K的状态、成本与下界；全部K解决前，单个K的OPTIMAL不提升为全局最优。可通过problem.for_count(K)检查指定K的完整MILP，不使用ALNS起点。

状态：2026-10-04 已实现完整联合 MILP。完整业务与成本定义见 [模型6设计](../../../../../docs/model6_joint_batch_cost_design.md)。需 gurobipy 与有效许可证。

model.py 构建完整联合 MILP，solver.py 负责总预算、求解、结果提取与证明信息，__init__.py 按需暴露 solve_exact。未依赖 ALNS 或固定分批的 M5 距离求解器。构建与优化共用总时间预算，单线程、零最优容差。

必须同时覆盖订单唯一分批 y、配送启用 z、整数容器池 N、两级路线、物理车启用与占用、二级趟次配送批次一致性、服务与交接时刻、截止分类、全取箱量、卸箱和清洗释放。2026-10-05 增加整数截点 c_b：批次起止固定，截点在给定上下界内优化，一级供货完成、回运阶段开始和空箱资格分类均绑定同一变量。E1弧筛选使用整个允许截点范围，不能沿用原固定截点误删可行路线。

二级送取不因进入第二阶段而停止。returned_i <= c_b 与 returned_i >= c_b+1 双向确定回运资格，恰好截点卸完计入当轮。供箱仍只计实际总仓卸箱加清洗后的释放。优化截点时 proof_scope 明确包含 cutoff，只有完整MILP最优且独立审计通过才证明该允许域的成本最优。

成本分别绑定实际公里、明确范围的工时、物理车启用逻辑或和非空趟次；容器峰值供给受 N 约束。批量需求是订单分配变量的线性汇总；箱数与截止/释放资格乘积需有限界线性化。使用整数 tick 建立截止和释放的双向链接，避免任意推迟符合资格的空箱。

建模前校验参数、单位、证据与合法候选域。只复用仍有效的业务工具，对依赖固定分批或距离的 M5 剪枝重新证明。模型内部目标值和独立成本重算逐项一致后才交付。

结果区分完整 MILP 已证明最优、限时可行、限时无解和已证明不可行。保留成本下界、gap、N、配送批次数、两级车辆/趟次/距离/工时及审计。成本最优与容器最少分别判断；全部结论包含候选时段、时间精度与趟次上限的限制。

路线流平衡结合一级访问序号和二级全局因果序号，排除零行驶时间导致的子环或跨趟因果环。每仓配送量按新分批汇总，回收量按二级实际卸回截止归属双向确定；只有已完成清洗的箱次可在领箱点计入库存。

这是便于审计的路线索引参考模型，规模随订单、候选时段和车辆趟次增长。限时可行解仍保留界与间隙，不保证所有中大实例在默认预算内获得最优证明。

2026-10-05 求解检查加入每趟的显式时长下界：回仓卸箱完成减出发时刻，不小于所选弧的行驶时间、访问服务时间和卸箱时间之和。该不等式本来由整数可行路线的时间传播蕴含，加入后加强线性松弛，避免仅依赖指示约束时出现负的计费时长下界；不改变整数可行域和经济目标，也不保证有限预算下的每次结果更好。
