# M3 / M4 / M7 标准同日回收 ALNS 对比

每个实例使用 seed=42、43、44；同规模各模型预算相同，串行运行。小规模 1 秒/次，大规模 3 秒/次，迭代上限 1,000,000。M7 使用当前默认四分仓候选池，分仓阶段占 75%，交接使用剩余 25%。

这些是短预算启发式结果，不是全局最优值；距离使用 Zhou 坐标单位。可行性来自模型自身评估器，另按输出路线独立复算距离。
