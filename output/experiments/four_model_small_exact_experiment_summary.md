# 四模型小规模精确求解实验总结

## 1. 实验说明

- 实验日期：2026-08-25
- 数据集：Zhou 延后包装回收数据集 `small/standard_same_day`
- 实例数量：22个，其中7顾客6个、10顾客8个、12顾客8个
- 数据质量：17个 `clean` 实例、5个 `repaired` 实例
- 模型范围：M1、M2、M3、M4
- 一级车辆数：2辆
- 二级车辆数：每个卫星站4辆
- 空容器重量：2
- 空容器体积：1
- 单个模型—实例组合时间上限：600秒
- M4精确形式：安全二级弧删减 `arc_pruning`

本次实验共完成88次精确求解。88个结果全部达到 `OPTIMAL`，没有出现
`TIME_LIMIT`、`SCRIPT_ERROR` 或 `INFEASIBLE`。

## 2. 模型定义与比较关系

| 模型 | 卫星分配 | 回收动作 |
|---|---|---|
| M1 | 固定分配 | 纯配送，不回收 |
| M2 | 自由分配 | 纯配送，不回收 |
| M3 | 固定分配 | 配送后延迟回收 |
| M4 | 自由分配 | 配送后延迟回收 |

主要对照关系如下：

- M2与M1：衡量纯配送场景下自由卫星分配的优化价值。
- M4与M3：衡量延迟回收场景下自由卫星分配的优化价值。
- M3与M1、M4与M2：反映加入延迟回收动作之后目标值和计算难度的变化。

## 6. 主要实验结论

1. 自由卫星分配具有稳定的目标值改进作用。M2在22个算例上全部不劣于M1，
   M4在22个算例上全部不劣于M3。
2. 在纯配送场景中，自由分配平均降低目标值15.96%；在延迟回收场景中，
   自由分配平均降低目标值12.16%。
3. 自由分配显著增加精确求解难度。M2平均求解时间约为M1的23.9倍，M4平均
   求解时间约为M3的16.1倍。
4. M4是当前四个模型中计算难度最高的模型，且实例间差异明显。最困难的
   `Set1_12-2-4` 用时401.738秒，但仍在600秒上限内证明最优。
5. `Set1_7-2-3b` 中M2与M1、M4与M3目标值均相同，说明该实例的固定卫星
   分配已经达到自由分配模型的最优值。
6. `Set1_10-2-1` 中M4与M3目标值相同，说明延迟回收条件下自由分配未带来
   额外收益，但求解时间从5.070秒增加到127.157秒。
7. M3和M4的目标值整体高于相应纯配送模型，符合增加回收节点、回收路径及
   配送—回收时序约束后的预期。
