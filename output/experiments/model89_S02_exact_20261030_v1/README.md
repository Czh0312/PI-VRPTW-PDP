## 补充：固定K=2精确诊断

M8全域最优方案选择K=2。额外用同一种子42、相同300秒预算固定M9的K=2，
订单、费用、车辆、箱池范围和秒级日历域保持原样，自由选仓仍由Gurobi决策。
