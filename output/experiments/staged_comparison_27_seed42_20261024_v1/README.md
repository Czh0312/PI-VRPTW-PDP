# 27算例、种子42的三阶段模型对照实验

117次正式调用全部完成，109次返回可行解并通过独立两周期审计，8次限时未找到可行解；没有已证不可行的结果，没有未处理的执行或审计异常。详细逐例结果见 [report.md](report.md)，发布前复核见 [release_validation.json](release_validation.json)。

## 主要结果

| 对照 | 中规模20顾客，9例 | 大规模50顾客，9例 |
| --- | --- | --- |
| 成本ALNS：M8相对M3 | 7例费用更低、2例更高；合计费用下降12.07% | 8例费用更低、1例更高；合计费用下降13.89% |
| 距离ALNS：M4相对M3 | 7例距离更短、2例相同；合计距离下降6.92% | 7例距离更短、2例更长；合计距离下降6.19% |

这里的合计降幅为“配对左侧指标总和减右侧指标总和，再除以左侧总和”，不是逐例百分比的算术平均。所有比较只对应本轮单种子、指定限时所得方案，不能据此认定模型或算法在所有算例中必然占优。

小规模7顾客、每种方法300秒：M3精确9/9例有可行解，其中8例已证最优、1例限时可行；M8精确仅S02有可行解，9例均达到时限；M8 ALNS为9/9例可行。S02中M8精确费用54.7805，M8 ALNS费用56.8870，二者差2.1064。这个差是限时可行参照差，不是最优gap；原始求解器界与gap字段保留在结果中供审阅。

成本ALNS中，M8的优势来自减少箱池采购：中规模9例合计箱池费用减少320、运输费用增加176.715103，净费用减少143.284897；大规模分别为885、501.782394、383.217606。每例配送数量不变，清洗及磨损费用不变。M03、M09、L07的M8费用较高，也已完整保留。

距离目标下，M3在18例中的路线均长于M1，循环包装收益需结合包装价格与重复使用次数判断。按照共同成本系数复算，首周期一次性包装单价阈值约为每次配送5.04—5.65；后续周期阈值约为0.04—0.65，单位均为合成费用单位。阈值不是市场报价。表格同时给出p=0/1/2/3/4/5的情景及条件回本周期，原模型未给出实际一次性包装单价或箱体寿命。

M3/M4用于观察自由选仓收益；大规模L02、L09在本轮ALNS中为负收益。有限搜索时间和单次随机轨迹会影响所得方案，负收益也保留在分母与表格中。

## 实验协议

| 阶段 | 方法与目标 | 每次预算 | 次数 |
| --- | --- | --- | ---: |
| A | 小规模M3精确、M8精确、M8 ALNS，成本目标 | 300秒 | 27 |
| B | 中大规模M3/M8 ALNS，成本目标 | 中600秒，大1200秒 | 36 |
| C | 中大规模M1/M3/M4 ALNS，距离目标 | 中1200秒，大1800秒 | 54 |

每档S/M/L的01—09全部纳入，种子42，串行运行；精确求解单线程，没有跨方法热启动。预算总和121500秒（33小时45分）。精确可能提前最优；预算覆盖建模与搜索，结果提取及校验有少量尾部开销，各次实际时间见runs表和row.json。

M8精确与ALNS统一K=1—4，批次边界与分界以60秒为决策步长；行驶、服务和时间窗保持原物理秒时钟。M3保留原固定单批日历，可含半分钟分界，因此不宣称本轮M3与M8离散允许域相互包含。

共同费用为 `0.1*D1 + 0.05*D2 + 5*N + 0.02*Q`，来自合成系数，未做真实货币或距离标定。`5*N`为一次采购，已包含在首周期总费用中，不重复加入同一初始投资。M1只复算运输费，一次性包装总费用保持为`Q*p`。在相同方案重复t周期、期间无需换箱且不计丢失与贴现的条件下：

`累计节省 = t*(Q*p - 额外运输费 - 清洗/追踪/磨损费) - 5*N`。

这些经济复算使用距离目标所得调度，不能称为费用最优结果。价格敏感性也不重新优化路线。

## 文件说明

- `manifest.json`及其SHA256：运行前冻结的117次调用协议、源码与输入哈希。
- `sources/current/`、`source_current.zip`、`driver.py`：正式运行实际使用的冻结源码；ZIP与展开文件均核对。
- `cases/`、`inputs/`、`input_audit.json`：冻结配置、物理及费用输入。输入审计本身不构成可行性证明。
- `runs/<job>/attempt_001/`：原始result、独立audit、可行解cost_replay、row、completion哈希和worker日志。没有补跑覆盖原始尝试。
- `tables/`：117次调用总表、小规模对照、成本收益、距离对照、包装价格阈值与108行情景表。
- `analysis.json`、`report.md`：冻结驱动器生成的完整汇总。
- `release_tools.py`、`release_validation.json`：发布前重新读取全部原始证据，以冻结源码重放109个可行解的两个连续周期，并独立核算费用和派生表。
- `selected_test_validation.json`：正式运行前的选定测试范围及结果（95个不同测试最终通过，0未解决失败、0跳过；不是全套测试）。`smoke_validation.json`记录13次短操作检查，它们不计入117次正式实验。
- `release_inventory.json`：本次发布文件的明确清单与内容哈希，清单本身除外。

运行锁、PID、live文件、启动器和本机环境文件不属于发布内容。复现方式见 [REPRODUCE.md](REPRODUCE.md)。
