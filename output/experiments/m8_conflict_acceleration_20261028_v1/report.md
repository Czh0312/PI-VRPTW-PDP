# 模型八：回收批次同步加强实验

新版在三个新种子（11、23、37）下，对 S03、S08、S05 均完成全域最优性证明。输入上下界、原始 K=1…7、完整子问题和 1e-6 绝对证明容差保持一致。

## 实际改动与原因

原完整模型已经规定，同一趟二级车的所有回收任务都在该趟结束时卸回仓库，并按第一个满足条件的截流时刻进入回收批次。原乐观主问题没有完整表达这层关系。新版仅对主问题增加两项有效必要条件：同趟带回的空箱必须同批回收；一趟车有配送任务时，其回收批次不能早于配送装载批次。原业务规则和最优解集合没有改变。

旧长跑 S03 的 643 个不同完整组合中，640 个违反新联系；S08 的 312 个中，312 个违反。它们过去最终都被完整子问题确证在原成本上限下无解。现在这类组合可由主问题直接排除，不必再逐一创建、求解子模型。

本版实现的是这组主问题同步约束。没有额外引入 IIS 冲突提取或模型模板复用：新增联系已把本轮候选的子问题检验量降至 S03 的 2 个组合，以及 S08/S05 的 0 个组合，因而先验证这项最小改动的收益和正确性。

## 独立正确性复核

新增联系先通过 12 项选定验证：独立完整原模型的小算例最优计划投影、细化时钟、三个实际原方案，以及完整分解求解与独立最优值一致。最终证据测试另有 45 项通过，合计 57 项通过、0 失败、0 错误、0 跳过；没有运行整个仓库测试集。项目运行器预检 READY，实际 Gurobi 版本 11.0.3。

最终证据包括原始输入/源码哈希、18 次预声明配对、成本和两周期业务审计。每个新版试验还独立重建全部主问题约束和记录割：仅使用旧下界，不设置最优值下界或目标等式，并取消 eta 的上界，用新种子 101 再求全局界。所有不同的新子问题割还恢复原始未裁剪车次槽位重新求证。
