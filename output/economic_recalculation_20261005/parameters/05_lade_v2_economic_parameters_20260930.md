# LaDe 杭州 V2 经济参数补充与核实

核实日期：2026-09-30。范围：现行 LaDe 21 组 AOI/日派生案例的条件经济分析。采用公开原始价目表、政府工资调查和研究报告补充参数；没有新增企业实测记录。

经济分析的数据底座仍是 **LaDe-D 杭州派生数据及保存的 OSRM 公里/分钟矩阵**。Zhou 坐标不直接代表公里，不适用本人民币配置。LaDe 提供需求与位置基础，不能提供循环箱采购、回收、清洗及车队账单。

本次新增：

- `config/cost/cases/lade_hangzhou_v2_single_batch.json`：B1、M1–M4，人民币口径与包装价格/寿命扫描。
- `config/cost/cases/lade_hangzhou_v2_multibatch.json`：B2/B3、M5，使用相同运营单价，按箱的使用次数分摊购置成本。
- [机器可读证据登记](lade_hangzhou_v2_evidence_20260930.json)：7 项来源、日期、PDF 页码与文件哈希、逐参数证据类型、公式、敏感性范围及缺口。

`config/cost/cases/lade_hangzhou.json` 是旧版嵌套配置，不替代上述新配置。旧版 900 箱、3% 损耗及运输全成本不自动继承。

## 1. 当前可用参数

“公开参照”表示来源真实，但未必匹配本案例；“换算”包含显式假设；“情景”尚无适用实测证据。所有金额均为人民币。

| 循环箱购置 | 36.5 元/箱 | 2022 年企业采访中的历史价格；不是 2026 年供应商报价 [S2] |

30 L、2 kg 箱体、每件一个箱、车辆容量和仓址仍是 V2 的结构假设。不能用上述“箱价有出处”反过来证明箱型、装载率或车队真实。零售价与采购价存在口径差异，因此低纸箱价格情景必须保留，不能只报告 4–5 元下有利于循环箱的结果。

较新的官方油价已核实：2026-09-24 浙江标准柴油最高零售价为 **9,675 元/吨** [S6]。该通知附件按吨报价，不能直接填入元/升字段。本轮没有取得可直接核对的最新浙江官方升价原文，故主配置保留明确日期的 8.45 元/L，扫描 7/8.45/9；没有把旧福建油价当作杭州当期油价。

## 2. 防止重复计费

当前费用模块按三类相互独立的运输费用计算：

`运输费用 = E1/E2 公里数×燃油维保单价 + 路线占用分钟×工资单价 + 实际启用车辆数×固定日费用`。

不能再将旧版 6.5／2.2 元/km 的“全成本”与本配置工资、车辆固定费用叠加。旧 iCET 18.6／8.2 是 **2025 年预测值**，不是观测年份更新后的实测油耗。新配置两层暂共用轻型柴油车代理，不能据此断言 E2 是柴油车；若采用电动三轮或电动微面，应一起校准车辆、能耗、电价和固定成本。

费用中的工作时间来自审计得到的每趟装车/出车准备开始至返场完成的占用时间，含趟内等待；并非企业全部付薪时数，趟间待命、交接班及加班制度未建立。日固定费用也只乘实际启用车辆，闲置自有车辆的不可避免成本未完整计入。因此仍不能称为企业完整损益表。暂无可核实路桥费、税额抵扣、场地成本和额外回收激励；这些未单列的项目不是实测为零。

工资、箱价和油价来自不同年份，未做统一基年平减。这是一套可复算的名义价格参考情景，不是 2026 年不变价预测。

## 3. 单批次与多批次怎样计箱体成本

令每天发出箱次为 `Q`，初始箱池为 `N`，箱价为 `P`，每箱寿命为 `L` 次使用。

- 初始投入始终为 `N×P`，随各案例及实际采用的池量计算，不使用旧配置固定的 900 箱。
- B1 默认 `N=Q`，每箱每天一次，此时“50 次使用”可对应“50 个运营周期”。现有单批现金流每 50 周期整池更新。若增大 N，50 周期仍只是预设更新政策，不能继续称等于每箱使用 50 次。
- B2/B3 可能同一天重复使用同一箱，应按 `Q×P/L` 分摊箱体损耗。新字段 `container_lifetime_uses` 实现该口径；输出 `container_use_depreciation_per_cycle` 与 `period_cost_with_use_depreciation`。

例如 N=100、Q=200、P=36.5、L=50，每周期箱体分摊为 **146 元**。若误用 `N×P/50` 会得到 73 元，把箱体消耗少算一半。减少 N 降低初始资金需求，但在同样 Q、P、L 下不自动减少按使用次数计的物理损耗。

按使用次数分摊是零残值、无丢失、无日历老化的线性费用分配，不提供逐箱更换时刻、融资或现金回本日期。初始投入不得与这项分摊再次相加形成“总现金支出”。代码禁止同时指定 `pool_amortization_cycles` 和 `container_lifetime_uses`。M5 尚无与 B1 同样的完整现金流对照入口。

## 4. 回收证据与当前模型的边界

2023 年报告表 2-5 转引一个七仓试验，给出 5.63 天周转、94.9% 回收；表 2-6 汇总浙江九轮试验，报告 10–50 次循环、95%–99.9% 回收 [S7]。本轮直接核对的是报告表格，**原始试验记录和征求意见稿编制说明未取得**，因此是二手试验线索，未写进可执行基准。

这与 V2 的当天配送、短时使用、全额归还不是同一种业务。不能将 5.63 天改成若干分钟后使用，也不能将 1−94.9% 直接作为永久丢失率：原始观察期限与迟返定义未核实。报告的 1–3 元“循环成本”脚注还提示可能只包括箱体购置分摊，不能据此声称清洗收费为 1–3 元。

若目标转为普通消费者电商包装回收，需要跨日库存、未归还箱龄、迟返与永久损失区分、补购和清洗产能，及匹配的实测分布。当前案例适合研究明确假设的日内周转箱服务；公开回收率不能只靠修改一个费用参数接入。

## 5. 运行与敏感性

单批次参考入口（示例只说明配置接入，论文应按实验方案运行多种子和足够预算）：

```sh
.venv/bin/python experiments/runs/run_single_batch_comparison.py \
  --case data/single_batch/small/lade_0823_10aoi/case.json \
  --solver alns --seeds 42 --time 2 --iterations 5000 \
  --economic-config config/cost/cases/lade_hangzhou_v2_single_batch.json
```

多批次对已保存结果重新审计计价，`--case` 应指向该运行的冻结配置，保证模型、矩阵和池量与路线一致：

```sh
.venv/bin/python main.py cost \
  --case /absolute/path/to/frozen_case.json \
  --route-result /absolute/path/to/result.json \
  --economic-config config/cost/cases/lade_hangzhou_v2_multibatch.json
```

B1 入口自动扫描纸箱价 `[1,2,3,4,5]` × 更新周期 `[10,20,30,50]`。其余敏感性网格在证据 JSON 中登记，**本次没有声称已经批跑**。优先分析清洗价、寿命、实际包材采购价、车辆与工资费用，再扫描各案例建议的池量。固定路线改变价格只能说明该路线的费用变化；重新优化或改变车辆/清洗时间需要另做可行性求解。

最需要补采的是：同规格箱体和纸箱的采购凭证、逐箱发出/归还记录、清洗工序及成本、车辆账单与能源日志、实际付薪工时。这些到位之前，可表述为“真实需求与路网基础上的公开参数校准情景”，不能表述为“真实运营数据证明盈利”。
