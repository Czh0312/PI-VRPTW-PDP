## 独立验证记录

Material Passport：Origin Skill=academic-research-suite/experiment-agent；Mode=validate；Date=2026-10-05；Status=ANALYZED；Version=cutoff_validation_v1。

3137项全仓测试通过；78个新可行解均通过库存与车辆连续两周期重放，以及费用、距离和需箱数重算；1954个历史有效结果仍可审计。250份源码、67份输入快照、77份历史起点候选的哈希一致。

统计/方法检查覆盖11/11项：

| 检查 | 本轮解释边界 |
| --- | --- |
| Simpson’s paradox | 逐例方向均为测试成本下降；不合并坐标距离与道路公里推断真实费用。 |
| Ecological fallacy | 结论限于给定优化场景，不推断企业或单件包裹实际经济收益。 |
| Berkson’s paradox | 7个有目的选取的代表场景，仅作探索验证，不代表186个配置总体。 |
| Collider bias | 按最低成本选解是明示决策规则，箱数不是最小箱数估计；没有回归控制分析。 |
| Base rate neglect | 完整报告84次尝试、78个有效解、6次无解限时及7个完整对照。 |
| Regression to the mean | 两组使用同一起点和新增预算；有限随机搜索仍不能证明大场景收敛。 |
| Survivorship bias | 6次限时无解和所有种子均保留；没有删除不利箱数变化。 |
| Look-elsewhere effect | 无显著性检验；7例全部展示，全部原始运行保留。 |
| Garden of forking paths | 费用不调整；界和预算显式冻结；属于探索实验，不是预注册确认研究。 |
| Correlation versus causation | 3个小例有数学成本最优证明；大例只报告已观察可行解，不推断真实运营因果收益。 |
| Reverse causality | 模型内时间先后由路线、回收和清洗约束确定；不作观察数据方向性因果推断。 |

这些是描述性优化结果，没有p值或统计显著性结论。部分运行期间回归测试并发执行，不作独占机器速度或收敛性能比较；限时精确解不标为最优。随机优化未完整重跑，独立重放和费用重算已复核。详细记录见independent_validation.json和full_tests.xml。
