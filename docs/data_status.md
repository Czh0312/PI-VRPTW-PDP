# 数据来源与缺口

2026-10-05进一步新增 **M5/M6共享主对比集** `data/model5_model6/shared_v1_20261005/manifest.json`：395个场景、790个模型配置及395个固定策略成本对照。两模型逐例读取相同物理输入，只通过配置区分固定决策与优化决策；见 [共享设计与验收](model5_model6_shared_dataset_20261005.md)。下述M6专用版作为来源继续保留。

2026-10-05另新增模型6专用 `model6_uniform_suite_v2`，395个配置，保留93个来源family的关系并去掉同源B2/B3日历替换后的重复。新增独立预约时间、三档窗口及清洗/资源/费用/到货/同点多订单敏感性，见 [设计与验收](model6_uniform_dataset_v2_20261005.md)。下文279配置仍专指M1–M5使用的旧静态V2主清单，未被覆盖。模型6新版时间与回收仍是显式情景假设。

2026-09-30 已完成 `static_batch_suite_v2` 的设计修订，七档 Zhou 各 10 例，连同补充资料共 93 组、279 个配置。现行规则与验收见 [修订记录](dataset_redesign_v2_20260930.md) 和 [数据入口](../data/README.md)。

| 数据 | 保留依据 | 情景假设或待核实内容 |
| --- | --- | --- |
| Zhou 派生 | 所选顾客/仓库坐标、货量、顾客服务时间 | 仓库子集、容量限定分区、旅行速度、箱数映射、预约窗口、使用时间和车队；坐标不是实测公里 |
| LaDe 派生 | AOI/日配送量、位置、保存的 OSRM 道路矩阵 | 前置仓与中心仓是代理点；包装箱数、货重、车辆、使用和回收时间、清洗及同周期全额归还 |
| 人工机制 | 2 个明确的构造例 | 全部字段均为机制假设，用于检验截止、迟返和箱池规则 |

V2 采用 08:00–21:00 的日内周转箱情景。两个 Zhou 同源情景共用位置、货量、箱数、资源和需求阶段，改变使用/预约回收时间。窗口使用公开可行构造生成，不是原论文窗口，也不是企业承诺时段的实测记录。LaDe 旧服务时段与历史派生回收量仍在来源/溯源文件中，不能解释为新版输入。

[此前设计审查](dataset_design_review_20260930.md) 针对 V1：37 小时周期、过量二级车辆、冗余使用约束、LaDe 第一批必迟返等已在 V2 修订；其中统计数值应作为历史诊断阅读。

仍缺企业实际容器交回时间、仓址确认、清洗能力、箱体寿命与损耗、成本与车辆工时校准。V2 可以用于明确假设下的算法对照，不代表真实经营经济性已验证。2026-09-30 已补充 [LaDe 人民币参考参数及证据](../reference/cost/05_lade_v2_economic_parameters_20260930.md)：包装报价、杭州工资统计、能源参考与显式情景假设分别标注，并提供单批/多批配置。公开参照不等于该企业实测成本；原 synthetic 演示价格也不能当作实测经营成本。

原始来源底稿保留。此前本地核对未找到 `data/real_case/raw/lade_d/delivery_hz.parquet` 和 `data/real_case/raw/r3pack/D3.5_R3PACK_Dataset.xlsx`；现有派生资料与来源哈希不等于原始文件已在本机就绪。此次修订没有声称重新采集或补齐这些实测数据。
