# M5 第八步：将距离证书转成有效约束

本轮接续 [独立距离下界](m5_exact_bound_certificate_20261001.md)，把已证明有效的距离界作为可选的
MILP 约束，比较它是否真正改善 Gurobi 的松弛和搜索。**默认仍只报告独立证书**；新增约束通过
`distance_cuts='total'` 或 `'components'` 显式启用。有限预算下，上界和下界可能分别改善或退步，
不根据单次最好结果切换默认配置。

## 约束形式及可行性依据

令 `D1[b]` 为第 b 批全部一层路线的距离，`D2[s]` 为仓 s 在整个周期内全部二层趟次的距离。
第七步证书分别提供有效下界 `L1[b]`、`L2[s]`，不要求原矩阵满足三角不等式。
一层下界允许通过其他仓绕行；二层界允许跨趟次、跨批回收，并对不同覆盖同一成本的界取最大值。
证明及计算方法沿用上述报告。

```text
total：       原目标距离 >= 完整周期的安全距离下界
components：  每个 D1[b] >= L1[b] 的安全值
              每个 D2[s] >= L2[s] 的安全值
```

分项约束作用于一个仓的**全部趟次之和**，不能把整个仓的界加在每个趟次上。
每个分项扣除 `1e-7 * max(1, bound)` 的数值裕量，只添加正下界行。
不增加变量、趟次限制或业务条件，不把可行方案的成本当下界；新增约束保持整数可行方案集合。
分项约束限制成本在不同批次、仓之间的分布，因而可以比一条总距离行更强。

索引表达直接累计每条独立弧的成本。共享二层内部弧的表达仅在全局内部弧处累计一次成本；
各趟的出仓、返仓弧分别计入所属仓。测试直接将所有分项表达的变量系数相加，与原目标逐项比较，
另将已审计时间表的全部初值固定后求解，检查成本及跨批回收仍被接受。

证书计算复用求解器已有结果，计入原总预算。独立调用 `build_model` 时才按相同总截止计算证书。
非适用范围、零界或证书超时不添加距离行；单批继续使用独立后端。
`use_distance_certificate=False` 不能与显式距离行同时使用。

## 入口与诊断字段

M5 的编号入口现可显式选择距离行，原调用方式保持默认行为：

```python
from models.routing.variants.model_5.exact import solve_exact
result = solve_exact(problem, time_limit=60, seed=42, distance_cuts='components')
```

`None` 和 `'none'` 均不添加距离行；`'total'` 添加至多一行；`'components'` 按批次、仓添加分项行。
共同求解器和 M5 建模入口也接受相同选项。实验工具的 `--mode distance-cuts` 比较三个配置，
`--variants reference components` 可只运行报告证书与分项行两个配置。

| 输出字段 | 含义 |
| --- | --- |
| `info.distance_cut_mode` | 本次选择的距离行模式 |
| `info.distance_cuts_added` | 实际添加的正下界行数 |
| `info.root_optimal_callback_observed` | 容量割回调是否观察到最优状态的根节点松弛 |
| `info.root_optimal_callback_seconds` | 首次观察到上述状态的 Gurobi 运行时间 |

最后两个字段记录**首次最优根节点 MIPNODE 回调**，不表示整个根节点割循环或分支搜索结束，
时间也不是日志中初次 LP 求解所用时间。`false` 表示没有观察到该状态；没有相应回调时不能据此判定 LP
未完成。实验另检查日志中的 `Root relaxation: objective ...` / `time limit`，保存初次 LP 的目标与用时。
Gurobi 原始界、独立证书界、最终有效界和最优性标志继续分别报告，证书不触发最优性证明。
实验冻结 JSON 使用旧诊断字段 `root_relaxation_completed` 和 `root_relaxation_first_complete_seconds`。
最终源码改用上表中更明确的名称，避免把首次回调观察与初次 LP 完成混淆；仅改遥测名称，求解逻辑不变。

## 同初解、同预算对照

全部输入、初始方案、源码、日志和结果冻结；初始方案逐个独立审计，两组使用相同种子。
两组自身初解构造仍开启，初解、证书、建模和求解均计入总预算。两组都启用原独立证书，
因此下表的差异来自完整模型新增距离行后的求解轨迹，不是关闭/打开报告证书的对照。
墙钟截断仍有运行波动，不能由少量实例推断普遍提速。

### 三种表达探索

30/50 顾客、seed=42、每次 15 秒，三组共 6 次，全部审计通过：

| 顾客数 | 距离行 | 可行距离 | Gurobi 原始下界 | 最终有效 gap | 观察到最优根松弛 |
| --- | --- | ---: | ---: | ---: | --- |
| 30 | 无 | 1,692.058358 | 1,098.321633 | 29.62% | 是 |
| 30 | 总距离 | 1,692.058358 | 1,190.944487 | 29.62% | 是 |
| 30 | 分项 | 1,689.535224 | 1,277.943592 | 24.36% | 是 |
| 50 | 无 / 总距离 / 分项 | 2,751.157237 | 0 | 46.55% | 否，日志为根 LP 限时 |

30 顾客分项表达的初次根 LP 目标为约 1,192.235，比原约 1,006.949 更强；随后实际 Gurobi 界超过
独立证书 1,190.944。这才是求解过程下界改善的证据。50 顾客增加 7 行、原始矩阵增加 9,666 个
非零项，15 秒仍不能完成根 LP；迭代次数变化不能单独解释为速度改善。

### 正式 15 秒对照

20/30/50 顾客、seed=42/43/44、无距离行/分项行，共 18 次。下表对每次 gap 先计算再求算术均值。

| 顾客数 | 可行距离均值：无行 / 分项 | Gurobi 原始界均值：无行 / 分项 | 最终有效 gap 均值：无行 / 分项 | 最优根松弛观察次数 |
| --- | ---: | ---: | ---: | ---: |
| 20 | 1,450.156496 / 1,456.497857 | 1,110.175548 / 1,141.611940 | 22.56% / 21.62% | 3/3 / 3/3 |
| 30 | 1,690.376268 / 1,691.217313 | 1,188.121766 / 1,300.899115 | 28.94% / 23.08% | 3/3 / 3/3 |
| 50 | 2,751.157237 / 2,751.157237 | 0 / 0 | 46.55% / 46.55% | 0/3 / 0/3 |

20 顾客 seed=44 的原模型找到 1,437.473776，分项行仍为 1,456.497857，说明下界更高也可能丢失
预算内的可行解改善。30 顾客三个种子的界均提高，但 seed=43/44 的可行距离从 1,689.535224
变为 1,692.058358，平均上界略有退步。此轮保留全部逐次结果，不只选择收益最大的种子。

### 小实例及 50 顾客延长预算

十个冻结输入、seed=42、5 秒两组，共 20 次，全部审计通过。七个小实例两组均证明最优，目标相同。
其余三个输入的可行距离也相同：20 顾客 1,456.497857、30 顾客 1,714.216798、50 顾客 2,751.157237。
20 顾客最终有效 gap 均为 23.71%；30 顾客从 30.53% 变为 30.45%；50 顾客均为 46.55%。
30 顾客原根 LP 限时，分项行的初次根 LP 已完成。20 顾客分项行的初次 LP 日志也已完成，但尚未触发
最优根节点回调，这进一步说明不能单凭回调标志判定初次 LP 是否完成。

50 顾客另以同初解、seed=42、60 秒运行两组，均审计通过：

| 配置 | 可行距离 | Gurobi 原始下界 | 最终有效下界 | 最终有效 gap | 初次根 LP 目标 / 用时 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无距离行 | 2,751.157237 | 1,428.618075 | 1,470.621828 | 46.55% | 1,356.412 / 19.00 秒 |
| 分项距离行 | 2,724.714374 | 1,508.780271 | 1,508.780271 | 44.63% | 1,474.376 / 16.32 秒 |

分项行在该次运行中同时改善了可行距离和实际搜索下界，最终界超过独立证书。
初次 LP 用时下降，但工作量从 32.26 增至 42.33；整个 MIP 工作量也从 116.54 增至 150.03。
这只是一个种子下的 60 秒诊断，不能由此认定普遍提速。20/30/50 顾客均未在本轮预算内证明最优。

正式 38 次、长预算 2 次、探索 6 次，共 **46 次重新审计通过**；证书逐项复算，距离行数、
无新增变量、有效界不超过可行目标、gap 计算及相同输入/初解均已核验。
