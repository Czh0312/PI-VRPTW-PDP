- Origin Skill：academic-research-suite / experiment-agent。
- Origin Mode：validate，用户授权的 M1–M4 连续优化。
- Verification Status：VERIFIED，限于保存的源码、定向测试、配对与独立审计。

## 结论

**regret 候选已全部撤回，不计入当前版本收益。** M1、M3、M4未通过开发筛选；M2开发均值较好，但正式验证未达到预登记条件。候选源码、20项测试、全部48次求解记录与退步保留；原破坏修复策略继续使用。随后执行的M3距离缓存是另一个独立候选，见[缓存提速记录](alns_single_batch_descent_cache_20261001.md)。

## 候选与确定性证据

在20个及以上订单的单批次求解中，加入初始权重0.5的 `destroy_regret` 算子，按现有相关性方式移除最多5个完整订单；配送插入优先选择最佳路线与次佳路线代价差最大的订单，回收保留截止时间顺序。不同位置在同一路线上不算不同备选路线，新趟算备选；缓存和距离下界只用于局部排名，完整解码及独立审计验收。

修复中断返回完整原状态，不暴露部分任务覆盖。评分复用当前固定分仓的准备评分器，备选缓存仅存在于本次修复，包含车辆就绪时刻并持有原路线对象，避免索引移动或对象ID复用造成混淆。

两组容量受限的单批次小反例均通过完整解码、独立审计和周期重放：M1贪心修复距离223，regret距离143；M3分别为154与84。新增20项测试通过，包括非度量距离、重复顾客、缓存与全评分逐值一致、中断完整性、无别名、固定种子重现和完整求解器入口。联合定向回归71通过。这些小反例不代表大规模收益。

## 协议与限制

- 开发：来源5-2场景02，嵌套50/100顾客，seed61/62，四模型，5秒。验证仅M2：来源10-2场景02，嵌套50/100，seed63/64/65，5秒；来源5-3场景02，100顾客，seed63/64，15秒。
- 源码、输入、预算、种子、模型筛选和采用规则在开发测量前登记。基线/候选次序交替，独立进程串行运行，等时对照时本任务未同时跑测试或CPU基准。
- 试验策略撤回后，候选算子、权重、启用逻辑和统计从默认求解器中删除，测试归档。后续缓存变更由另一协议单独验证；M5未由本轮修改。
- 母几何在此前轮次出现过，嵌套规模依赖，模型筛选也是观察数据后的选择。少量种子提供描述统计，机器负载未完全控制，不宣称显著性、全数据集改善、15秒以上表现或全局最优。
- 统计谬误11/11检查：模型/预算分层、不外推均值、说明选择/依赖、不作碰撞变量调整、保留分母、避免极端样本、保留退步、不作显著性筛选、预登记选择、说明负载、固定预算并谨慎解释时间差异。
