## 历史结果

迁移前已经生成的 `results/` 和 `output/` 文件没有批量改写，避免把
既有实验证据与新运行结果混在一起。因此，旧结果文件内的 `model` 字段以及文件名
仍可能使用旧编号。引用历史结果时，应先按上表换算，并注明“legacy numbering”。

迁移后重新运行实验时，新文件名和结果字段必须使用新编号。例如：

- 旧 `M7 <= M1` 对比现在写作 `M2 <= M1`；
- 旧 `M6 <= M2` 对比现在写作 `M4 <= M3`；
- 原来的主线 `M1/M7/M2/M6` 现在统一为 `M1/M2/M3/M4`。

旧编号诊断结果已集中到 `archive/legacy_results_pre_renumbering/`，不再放在当前
`results/` 主目录中。

曾经基于 Zhou 数据生成、但仍使用旧编号和旧扁平数据路径字段的结果，已原样归档到
`archive/zhou_results_pre_renumbering/`。这些文件没有重写；需要引用其中数值时，
必须同时换算模型编号，并注明其属于迁移前结果。
