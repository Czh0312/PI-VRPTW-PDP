# 单批次 ALNS：车辆就绪筛选修正（2026-10-01）

## Material Passport

- Origin Skill：academic-research-suite / experiment-agent。
- Origin Mode：validate，用户授权的单批次 M1–M4 连续优化。
- Verification Status：VERIFIED，限于保存的反例、冻结源码、配对、审计、回归与工作区复现。

## 采用决定

**保留 M1–M3 下降邻域的筛选修正，不能将本轮表述为普遍提速或稳定降低距离。** 修正确实找回了原实现误删的可行短路线，但本轮大规模收益很小且有退步：正式验证中 M1/M2 的15秒均值上升，M3一次5秒距离上升9.39%；一组M1固定迭代CPU中位数上升12.93%。完整数据均保留。

M4 的下降策略继续禁用，作为搜索未改变的对照；其距离和耗时也有波动，不能将这类变化归因于筛选修正。M5、精确求解器、容量约束、时间窗、分仓规则及独立审计没有由本轮修改。

## 修正内容与确定性证据

原筛选使用最好解解码得到的前一趟完成时刻。跨路线移动把前一趟缩短或删掉后，这个旧时刻可能高于新方案的车辆实际就绪时刻，从而误删可行方案。现在先按原候选顺序筛选，再把原先被拒绝的请求归属移动放到延后队列；原队列耗尽后，使用局部乐观前缀重新计算同车就绪时刻。空趟不占用车辆，显式出发/返回等待仍保留。

另修正两项配套问题：解码器忽略空趟，筛选上下文现在按非空原路线索引对齐；`depart_after` 是绝对出发下界，不应在此下界后重复加入准备时间。准备时间修正在筛选副本上进行，原始评分器和准备评分器的现有算术、输入等待提示均保留。

货物准备、已解码车辆时刻和乐观前缀按完整状态键复用，仅属于本求解问题和当前最好解。路线、车辆、E1排程或等待提示改变即刷新。中断不返回部分候选，也不缓存部分前缀。

两组独立审计的确定性反例，原方案距离均为42：

| 模型 | 原筛选结果 | 修正后距离 | 距离减少 | 独立审计 / 周期重放 |
|---|---|---:|---:|---|
| M1 | 删除前趟并合并后趟的可行方案被拒绝 | 23 | 19 | 通过 |
| M3 | 同类配送/回收合并方案被拒绝 | 25 | 17 | 通过 |

这只是小反例的确定性改进，不是大规模平均收益。原始实现先运行反例测试，得到预期的4失败、2通过；修正后扩展的21项测试全部通过，覆盖原始/准备评分器、显式等待、空趟索引、候选优先级、无别名、缓存刷新、中断、跨车辆回收等待及局部通过而完整解码拒绝的后缀冲突。

## 同时间大规模对照

16对开发、32对正式验证，基线和候选各48次，**96次求解全部通过独立审计和周期重放**。每对按 `(候选距离/基线距离−1)×100%` 计算后等权平均；负数表示距离下降。正式验证每模型六对5秒、两对15秒。

| 模型 | 5秒平均距离变化 | 改善 / 持平 / 退步 | 5秒最大单次退步 | 15秒平均变化 | 改善 / 持平 / 退步 |
|---|---:|---:|---:|---:|---:|
| M1 | -0.32% | 3 / 1 / 2 | +0.54% | +1.34% | 0 / 0 / 2 |
| M2 | -1.13% | 5 / 0 / 1 | +0.55% | +1.18% | 0 / 0 / 2 |
| M3 | -0.20% | 4 / 0 / 2 | +9.39% | -0.99% | 2 / 0 / 0 |
| M4，搜索未改变 | +0.58% | 2 / 1 / 3 | +4.07% | -3.11% | 2 / 0 / 0 |

开发四对/模型的平均变化：M1 **-0.26%**，M2 **+0.35%**，M3 **+1.41%**，M4 **+2.40%**。开发M3四对均退步，不能只引用正式验证的负均值。

确定性反例恢复是采用的必要条件。质量保护规则在看到开发结果前登记：所有最终审计有效；若改变的模型任一短/长预算均值上升超过2%，或单次退步超过10%，优先仅保留诊断实现。M1–M3均未触发这个保护规则，因此保留修正；这是容忍有限退步的正确性修正门槛，并非“均值必须改善”的性能采用门槛。搜索未改变的M4不接受策略筛选。

**新增恢复路径在开发大规模实验仅返回1个局部候选，正式验证返回0个。** 原队列常在预算结束或最好解更新前仍未耗尽。因而没有证据证明此误筛是这些大规模实例的主要瓶颈，也不能把全部距离差异归因于恢复路径。`descent_recovered` 计数仅表示局部筛选后返回的提案，不表示已审计的最好解改善次数。

## 固定迭代效率

两个100顾客来源、四模型、固定300迭代、seed42，每版三个独立进程重复，交替串行运行；60秒上限未触发。48次运行全部通过审计和周期重放，每组前后所有最终路线、分仓、距离和迭代数逐值一致。CPU不含加载、外部审计或profiler。

下表为CPU中位数变化 `(候选/基线−1)×100%`；正数表示变慢。

| 模型 | 来源5-1b | 来源10-1 |
|---|---:|---:|
| M1 | +12.93% | -0.40% |
| M2 | -0.68% | -1.88% |
| M3 | -0.51% | -0.07% |
| M4，搜索未改变 | +2.63% | -7.01% |

这些是描述统计。未改变搜索的M4也有明显耗时变化，M1同一来源各重复的相对变化亦不一致；不作稳定提速或因果归因。更完整的局部复查可能增加工作量，本轮明确保留并披露该代价。

## 协议、复现与边界

- 开发：来源5-2场景02，嵌套50/100顾客，seed56/57，5秒，16对。验证：来源5-3场景02，嵌套50/100，seed58/59/60，5秒，24对；另来源10-1场景02，100顾客，seed58/59，15秒，8对。
- 协议、种子、预算和门槛预登记。首批32个工作进程因开发输入目录未复制而在加载前全部失败，没有开始求解；失败日志保留。随后补齐相同预登记母例的已有冻结输入，种子/门槛/清单未改，再执行完整计划。
- 源码/输入冻结，独立进程前后次序交替，串行运行。本任务未在等时对照时并行运行CPU基准或测试。共享机器其他负载未完全控制。
- 试验源码存在两项其他聊天新增的精确求解/审计文件，ALNS路径不调用它们；最终采用快照由轮前快照加本轮三项ALNS文件构成，排除这些新增文件。工作区其他改动没有整体恢复。
- 定向回归112通过；新增测试21通过；最终完整回归 **1102 passed, 14 warnings in 63.56s**。
- 最终采用快照与工作区，在两个100顾客来源、四模型、固定300迭代的八组结果逐值一致，全部重新独立审计和周期重放通过。源码、输入和本轮修改文件最后一次SHA256核验无漂移。
- 母几何已在此前轮次出现过，不是完全未见数据；嵌套规模存在依赖。少量种子只支持描述统计，不宣称显著性、全数据集改善、15秒以上表现或接近全局最优。没有重算或证明新的GAP，距离变化不等于最优性GAP。

统计谬误检查11/11：按模型/预算分层；不外推局部均值；说明来源选择；不作碰撞变量调整；保留失败和完整分母；不挑极端种子；不删退步；不按显著性挑结果；预登记且保存选择；说明负载与依赖；固定预算并谨慎解释时间差异。

## 后续值得检验的方向

本轮恢复路径的触发次数提示，继续显著改善大规模质量不能只依靠这个筛选补丁。当前破坏修复最多移除5个完整订单，修复固定按配送截止时间插入，再插入回收；可检验随停滞调整移除规模、按最佳与次佳插入代价差选择先插入的请求，以及把多次搜索中的好路线组合成完整可行解。这些候选尚未在本轮实现或验证，不计入当前收益。约束与周期审计仍应作为最终验收依据。
