## 最终采用范围

**M1–M4均保留单批次准备解码器的静态载荷摘要缓存。** 两组100顾客、固定300迭代的前后路线、分仓、目标值和迭代数全部一致。两来源CPU综合几何平均降幅分别为M1 4.64%、M2 4.00%、M3 2.89%、M4 2.96%。

24对、48次等时求解全部通过独立审计及周期重放，各模型都通过预登记的CPU与质量门槛。质量并非每模型/预算都改善：M3在5秒下平均距离+1.97%，15秒下接近持平；M4在15秒下平均距离-5.19%。这是有限样本的计算提速及质量观察，不是普遍质量保证或GAP下降证明。

## 候选及正确性

完整解码原先在每次状态变化后，重新遍历每条路线，生成配送批次集合并分别计算初始配送重量、体积。即使只改动了另一条路线，这些静态结果也会重复计算。

候选在单批次准备解码器内，以完整、有序的`(order_id, kind)`序列为键，建立默认最多512项的实例内LRU，仅复用配送批次集合、初始配送重量和体积三个值。路线反转、重复订单、配送/回收种类都会改变键。重量、体积仍分别按原顺序`sum`，不重排浮点加法。摘要只含不可变的批次集合及数值。

只复用固定任务属性。各事件载荷更新、供货时间、车辆复用、显式等待、配送回收前序、时间窗、覆盖和库存检查仍由完整解码重算；输出事件和路线对象每次新建，不缓存可行性、排程或目标值。未知配送任务回退原解码路径，保留外部错误及覆盖检查顺序。`load_capacity=0`可关闭该缓存；未准备的参考解码和多批次路径继续使用原载荷计算。

前两轮采用的M3下降邻域距离缓存及修复距离缓存保留。未改破坏修复策略、候选排序、退火温度、重启或分仓搜索策略。

21项新增测试覆盖有向/非度量/零距离、多模型多种子下100次扰动逐值解码比较、关闭缓存、缓存容量与驱逐、浮点非结合性的原始累加顺序、重复任务和种类、错误优先级、改变供货/等待/路线顺序、完整独立审计、输出对象隔离和新问题上下文重新准备。联合定向回归91项通过。

## 预登记与采用规则

先冻结基线与输入，登记逐模型采用门槛，随后测量；没有在结果出来后改门槛或另选新的子集规则。

CPU主比较：两个100顾客来源5-2/10-1、scenario01，四模型、seed82、固定300迭代、60秒上限，每版三个独立进程重复，交替串行，共48次。全部最终路线、分仓、目标值、迭代数一致且审计/周期重放有效为总体正确性门槛。每模型两个来源的CPU中位耗时比取几何平均，要求综合降幅至少2%，且任一来源中位耗时退步不超过5%。上限未触发；CPU计时排除加载、profiler及求解后的额外独立审计。

等时比较：短预算来源5-3、scenario01嵌套50/100顾客，四模型、seed83/84、5秒，共16对；长预算来源10-2、scenario01的100顾客，四模型、seed83/84、15秒，共8对。所有24对、48次结果包含失败及退步均保留。按模型和预算分别计算配对距离百分比均值；每模型每预算平均退步不超过2%、任一单次不超过10%、全部审计/周期重放有效，且先通过本模型CPU门槛，才能采用。

如果只有部分模型通过，须在相应公开入口及分仓上下文显式关闭未通过模型的摘要缓存，再验证四模型的基线、最终源码和工作区固定迭代结果逐值一致；无法隔离则撤回候选。单个模型的退步不能被其他模型的改善抵消。

## 等时质量与最终采用

每对变化为`100 × (候选距离 / 基线距离 − 1)`，负数表示路线距离下降。每预算/模型取配对百分比的等权平均。

| 模型 | 5秒平均距离变化（4对） | 15秒平均距离变化（2对） | 5秒改善/持平/退步 | 15秒改善/持平/退步 |
|---|---:|---:|---:|---:|
| M1 | -2.08% | -3.07% | 3 / 0 / 1 | 1 / 0 / 1 |
| M2 | -1.38% | +0.14% | 3 / 1 / 0 | 1 / 0 / 1 |
| M3 | +1.97% | +0.01% | 1 / 0 / 3 | 1 / 0 / 1 |
| M4 | +0.00% | -5.19% | 2 / 0 / 2 | 2 / 0 / 0 |

全部24次基线及24次候选均审计/周期重放有效，没有从分母移除失败或退步。四模型在两个预算都通过门槛，最终采用范围与原全部启用候选完全一致，没有事后关闭模型或改动阈值。

M3短预算均值为+1.968079%，距离+2%门槛只有0.031921个百分点；最大单次退步+4.665350%。应将其视为提速通过而短预算质量接近退步门槛，不能宣称M3路线质量提升。15秒M2/M3的平均变化分别+0.135131%/+0.010048%；M4两对都改善，均值-5.190204%。

M3短预算按规模分别为50顾客平均+2.26%、100顾客平均+1.68%。50顾客均值高于2%，原预登记门槛是每模型/预算均值，未要求每规模分别通过；这里明确保留该退步，不将总体通过解释成每个规模通过。

规模细分也保留在原始记录中：短预算的50/100顾客是同一来源的嵌套案例，各仅两种子；长预算另一个来源的100顾客，仅两对。不能用总体均值证明所有规模改善，也不能据此推断预算增加的因果效果。
