# 可循环容器经济成本对比模型

## 1. 对比逻辑

经济分析不应只比较两条总成本曲线，而应把业务模式变化和算法改进分开：

| 层级 | 路径模型 | 经济含义 |
|---|---|---|
| 一次性固定分仓 | Model 1 | 只配送，不回收空箱，沿用给定分仓 |
| 一次性自由分仓 | Model 2 | 在 Model 1 上内生化顾客—前置仓分配 |
| 循环基准 | Model 3 | 配送并回收空箱，不使用中转优化 |
| 自由分配优化 | Model 4 | 在 Model 3 上内生化顾客—前置仓分配 |
| 异步交接/路径优化 | Model 6 | 在固定分仓的 Model 3 上扩展异步交接 |
| 自由分仓 + 异步交接 | Model 7 | 在同一可行解中兼顾 Model 4 与 Model 6 的功能 |

因此需同时报告两组同自由度比较：Model 1→3 是固定分仓闭环运输增量，Model 2→4
是自由分仓闭环运输增量；Model 1→2 和 Model 3→4 分别测量一次性侧与循环箱侧的
自由分仓价值。Model 6 直接继承 Model 3 可行解，Model 7 直接继承 Model 4 可行解，
其纯中转收益用同次运行的继承值与最终值之差测量。

## 2. 核心公式

设一个代表性运营期内使用循环箱 (Q) 次。六个模型的运输成本分别为
(T_1,T_2,T_3,T_4,T_6,T_7)，一次性包装单次成本为 (c_s)，循环箱每次清洗、扫码和损耗
补充成本为 (c_r)。则：

```text
包装替代毛收益       = Q × (c_s - c_r)
一次性自由分仓收益   = T_1 - T_2
固定分仓闭环增量     = T_3 - T_1
自由分仓闭环增量     = T_4 - T_2
循环箱自由分仓收益   = T_3 - T_4
M6 中转直接收益      = T_3,inherited - T_6
M7 中转直接收益      = T_4,inherited - T_7
所选方案净边际收益   = Q × (c_s - c_r) - (T_RU,selected - T_SU,selected)
```

经济测算在 M1/M2 中选择运输成本最低的一次性路线，在 M3/M4/M6/M7 中选择运输成本
最低的循环箱路线。价值分解采用与所选一次性方案具有相同分仓自由度的循环基准：若
选择 M2，则以 M4 为循环参考；若选择 M1，则以 M3 为循环参考。限时 ALNS 结果必须称为
“当前预算下的可行解”，不能称为模型全局最优。

当前成本复跑采用 incumbent-preserving 嵌套设计：M1/M3 各运行 10 秒；M2 继承 M1、
M4/M6 继承 M3、M7 继承 M4，并各追加 2 秒扩展搜索。这样扩展模型至少保留基模型路线，
M3→M6 与 M4→M7 的差额不会混入两次独立普通 ALNS 的随机搜索差异。

容器池初始投资为 (F=N_{pool}p_r)。若净边际收益 (S>0)，回本期数为
(F/S)；若 (S\leq0)，增加运营期数不会使方案回本，此时必须报告临界包装价格、
临界容器密度或其他敏感性条件。

## 3. 成本项

- 一次性方案：运输、包装购置、末端处置；
- 循环方案：运输、初始容器池、清洗分拣、追踪扫码、损耗补充；
- 运输成本分别用 E1 和 E2 距离乘以对应全成本单价；
- 参数和中国大陆来源见 `reference/cost/00_README.md`。

## 4. 当前 LaDe-D 代表日结果

数据为 LaDe-D 杭州 08-29 代表日，使用同一 OSRM 道路矩阵与 `seed=42`。基准参数下：

| 指标 | 结果 |
|---|---:|
| 一次性侧采用 | Model 2，396.62 元/期 |
| 循环箱侧采用 | Model 4，536.90 元/期 |
| 包装替代毛收益 | 546.18 元/期 |
| M2→M4 闭环运输增量 | 140.28 元/期 |
| M6 / M7 中转直接收益 | 均为 0.00 元/期 |
| 采用 Model 4 后净边际收益 | 405.89 元/期 |
| 回本周期 | 80.93 期 |
| 300 期净节省 | 88,918.34 元 |

与旧的 M1/M3/M4/M6 口径相比，加入 Model 2 后一次性侧运输基线由 483.21 元/期降至
396.62 元/期，因此回本期由 64.56 期修正为 80.93 期。Model 7 已纳入，但在本代表日
继承的 M4 路线附近未发现正收益交接，最终与 M4 路线相同。

## 5. 输出与复现

```bash
python main.py cost --case config/cases/lade_hz_0829.json --time 10 --extension-time 2
```

Model 6 中转机制的长预算、多种子和逐次中转审计仍可使用：

```bash
python experiments/runs/run_m6_transshipment_validation.py \
  --total-time 90 --stage1-ratio 0.75 --seeds 42 43 44 \
  --sample-pickups 0 --sample-locations 0 \
  --sample-carriers 0 --position-top-k 0
```

成本主分析与算法规模实验一致，采用基模型时间加扩展时间的嵌套口径；上面的 90 秒
多种子运行属于中转机制诊断，不替代主表中的 10+2 秒方案比较。

默认输出目录为 `output/economic_analysis/`：

- `economic_report.md`：中文结论；
- `summary.json`：全部路线与成本指标；
- `value_decomposition.csv/png`：价值来源分解；
- `mechanism_comparison.csv`：M1→M2、M1→M3、M2→M4、M3→M4、M3→M6 和 M4→M7；
- `route_model_comparison.csv`：六个模型的路线、预算、运输成本与是否入选；
- `horizon_cost_curve.csv/png`：累计成本曲线；
- `scenario_summary.csv`：包装价格等情景；
- `loss_rate_sensitivity.csv`：损耗率敏感性。

## 6. 解释限制

Zhou later-pickup 坐标不是已核验的道路公里。当前配置暂按 1 坐标单位等于 1 km
进行情景测算，所以绝对金额不能直接作为企业预算；路径间的相对距离差仍可用于评价算法。
正式论文若报告绝对人民币结果，应改用真实公里数据，或用可追溯的比例尺校准
`analysis.distance_scale_to_km`。
