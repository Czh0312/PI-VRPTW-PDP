# 可循环容器经济成本对比模型

## 1. 对比逻辑

经济分析不应只比较两条总成本曲线，而应把业务模式变化和算法改进分开：

| 层级 | 路径模型 | 经济含义 |
|---|---|---|
| 一次性基准 | Model 1 | 只配送，不回收空箱 |
| 循环基准 | Model 3 | 配送并回收空箱，不使用中转优化 |
| 自由分配优化 | Model 4 | 在 Model 3 上内生化顾客—前置仓分配 |
| 异步交接/路径优化 | 当前配置的 Model 6/7 | 从 Model 3 扩展中转或路径机制 |

因此，Model 1 到 Model 3 的差额反映“建立闭环回收所增加的运输成本”，
Model 3 到 Model 4 的差额反映“自由分配价值”，Model 3 到 Model 6/7 的差额
只能作为独立算法运行结果的方案差。Model 4 和 Model 6/7 是并列分支，不能写成
连续的 M3→M4→M6 改进链；Model 6 的纯中转收益必须在同一次运行内部测量。

## 2. 核心公式

设一个代表性运营期内使用循环箱 (Q) 次。四个模型的运输成本分别为
(T_1,T_3,T_4,T_6)，一次性包装单次成本为 (c_s)，循环箱每次清洗、扫码和损耗
补充成本为 (c_r)。则：

```text
包装替代毛收益       = Q × (c_s - c_r)
闭环回收运输增量     = T_3 - T_1
自由分配收益         = T_3 - T_4
中转直接收益         = T_6,before - T_6,after
独立路线结果差       = T_3 - T_6（包含普通 ALNS 搜索差异）
M4 与 M6 方案差      = T_4 - T_6
所选方案净边际收益   = Q × (c_s - c_r) - (T_selected - T_1)
```

经济测算在 M3、M4 和 M6/7 的已获得可行路线中按 E1/E2 运输成本选择方案；同时保留
所有原始路线与上述并列机制差额。若使用限时 ALNS，必须称为“同预算观测结果”，不能
称为模型全局最优。

其中 `T_6,before` 是同一次 Model 6 运行的第一阶段无中转路线，`T_6,after` 是在该
路线基础上执行中转搜索后的路线。只有二者差值能归因于中转；独立运行的 M3−M6 会
混入普通 ALNS 的随机搜索差异。

容器池初始投资为 (F=N_{pool}p_r)。若净边际收益 (S>0)，回本期数为
(F/S)；若 (S\leq0)，增加运营期数不会使方案回本，此时必须报告临界包装价格、
临界容器密度或其他敏感性条件。

## 3. 成本项

- 一次性方案：运输、包装购置、末端处置；
- 循环方案：运输、初始容器池、清洗分拣、追踪扫码、损耗补充；
- 运输成本分别用 E1 和 E2 距离乘以对应全成本单价；
- 参数和中国大陆来源见 `reference/cost/00_README.md`。

## 4. 当前算例的示范结果

数据为 `Set1_7-2-1b`，每期 7 个容器，路径算法每模型运行 5 秒。基准参数下：

| 指标 | 结果 |
|---|---:|
| 包装替代毛收益 | 16.13 元/期 |
| 闭环回收运输增量 | 180.02 元/期 |
| Model 4 自由分配收益 | 244.33 元/期 |
| Model 6 异步交接收益 | 0.00 元/期 |
| 采用 Model 4 后净边际收益 | 80.45 元/期 |
| 回本周期 | 45.37 期 |
| 300 期净节省 | 20,484.16 元 |

该小算例说明漏掉 Model 4 会改变经济结论：Model 6 在 5 秒预算内没有改善 M3，
但 Model 4 通过自由分配显著降低了运输成本。不过 Zhou 坐标并非已核验道路公里，
因此这些人民币绝对值仍只能用于流程演示；正式经济结论以 LaDe-D + OSRM 案例为主。

## 5. 输出与复现

```bash
python generate_cost_analysis.py --time 30
```

Model 6 中转机制的扩展预算、多种子和逐次中转审计使用：

```bash
python scripts/run_m6_transshipment_validation.py \
  --total-time 90 --stage1-ratio 0.75 --seeds 42 43 44 \
  --sample-pickups 0 --sample-locations 0 \
  --sample-carriers 0 --position-top-k 0
```

Model 6 ALNS 的默认时间分配现为第一阶段 75%、中转阶段使用剩余时间且上限 30 秒；
回收点、交接位置、接收车辆和插入位置默认不再抽样。因而总预算为 60/90/120 秒时，
中转阶段最多分别获得 15/22.5/30 秒。10 秒经济同预算筛选仍只会得到约 2.5 秒，
不能替代上面的扩展机制验证。

默认输出目录为 `output/economic_analysis/`：

- `economic_report.md`：中文结论；
- `summary.json`：全部路线与成本指标；
- `value_decomposition.csv/png`：价值来源分解；
- `mechanism_comparison.csv`：M1→M3、M3→M4、M3→M6/7 和 M4 vs M6/7；
- `horizon_cost_curve.csv/png`：累计成本曲线；
- `scenario_summary.csv`：包装价格等情景；
- `loss_rate_sensitivity.csv`：损耗率敏感性。

## 6. 解释限制

Zhou/Solomon 风格坐标不是已核验的道路公里。当前配置暂按 1 坐标单位等于 1 km
进行情景测算，所以绝对金额不能直接作为企业预算；路径间的相对距离差仍可用于评价算法。
正式论文若报告绝对人民币结果，应改用真实公里数据，或用可追溯的比例尺校准
`analysis.distance_scale_to_km`。
