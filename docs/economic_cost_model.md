# 可循环容器经济成本对比模型

## 1. 对比逻辑

经济分析不应只比较两条总成本曲线，而应把业务模式变化和算法改进分开：

| 层级 | 路径模型 | 经济含义 |
|---|---|---|
| 一次性基准 | Model 1 | 只配送，不回收空箱 |
| 循环基准 | Model 3 | 配送并回收空箱，不使用中转优化 |
| 循环优化 | 当前配置的 Model 6/7 | 在循环基准上加入中转或路径优化 |

因此，Model 1 到 Model 3 的差额反映“建立闭环回收所增加的运输成本”，
Model 3 到优化模型的差额才是“路径优化本身创造的经济价值”。

## 2. 核心公式

设一个代表性运营期内使用循环箱 (Q) 次。三个模型的运输成本分别为
(T_1,T_3,T_o)，一次性包装单次成本为 (c_s)，循环箱每次清洗、扫码和损耗
补充成本为 (c_r)。则：

```text
包装替代毛收益       = Q × (c_s - c_r)
闭环回收运输增量     = T_3 - T_1
路径优化收益         = T_3 - T_o
优化后净边际收益     = 包装替代毛收益 - 闭环回收运输增量 + 路径优化收益
                     = Q × (c_s - c_r) - (T_o - T_1)
```

容器池初始投资为 (F=N_{pool}p_r)。若净边际收益 (S>0)，回本期数为
(F/S)；若 (S\leq0)，增加运营期数不会使方案回本，此时必须报告临界包装价格、
临界容器密度或其他敏感性条件。

## 3. 成本项

- 一次性方案：运输、包装购置、末端处置；
- 循环方案：运输、初始容器池、清洗分拣、追踪扫码、损耗补充；
- 运输成本分别用 E1 和 E2 距离乘以对应全成本单价；
- 参数和中国大陆来源见 `reference/cost/00_README.md`。

## 4. 当前算例的示范结果

数据为 `Set1_7-2-1b`，每期 7 个容器，路径算法每模型运行 5 秒。基准参数下：

| 指标 | 结果 |
|---|---:|
| 包装替代毛收益 | 16.13 元/期 |
| 闭环回收运输增量 | 180.02 元/期 |
| Model 6 路径优化收益 | 0.00 元/期 |
| 净边际收益 | -163.89 元/期 |
| 300 期净节省 | -52,815.56 元 |
| 临界一次性包装价格 | 27.41 元/个 |
| 临界容器密度 | 78.10 个/期 |

这意味着该小规模、低密度算例不能证明循环箱具有经济优势。它反而明确指出了原因：
回收运输增量远大于每期包装节省，且该算例中 Model 6 未进一步缩短 Model 3 路线。
论文应把这一结果作为边界条件，并用更高业务密度、真实公里数据和路径优化确实生效的
算例检验经济性，而不是人为调整成本参数以制造正结论。

配置同时保留“15 元强化包装 + 增量运输仅计燃油”的敏感性情景。该情景用于回答
成本归属变化后何时转正：当前示范算例的净边际收益为 43.59 元/期，约 83.73 期回本，
300 期净节省约 9,427.57 元。该情景不替代包含人工、折旧、路桥、维保和保险的
运输全成本主结论。

## 5. 输出与复现

```bash
python generate_cost_analysis.py --time 30
```

默认输出目录为 `output/economic_analysis/`：

- `economic_report.md`：中文结论；
- `summary.json`：全部路线与成本指标；
- `value_decomposition.csv/png`：价值来源分解；
- `horizon_cost_curve.csv/png`：累计成本曲线；
- `scenario_summary.csv`：包装价格等情景；
- `loss_rate_sensitivity.csv`：损耗率敏感性。

## 6. 解释限制

Zhou/Solomon 风格坐标不是已核验的道路公里。当前配置暂按 1 坐标单位等于 1 km
进行情景测算，所以绝对金额不能直接作为企业预算；路径间的相对距离差仍可用于评价算法。
正式论文若报告绝对人民币结果，应改用真实公里数据，或用可追溯的比例尺校准
`analysis.distance_scale_to_km`。
